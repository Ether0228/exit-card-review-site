Q1. The graph of f(x) = -1.5*(x+3)^4 + 4 is shown above. To sketch this graph, which transformation should you apply first?

errorId: err-poly-trans-order | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Students often apply horizontal and vertical translations before considering stretches/reflections, which changes the graph incorrectly.

Remediation → err-poly-trans-order | Retest → err-poly-trans-order

  1. ✓ A. Vertical stretch by factor 1.5 and reflection in the x-axis (a = -1.5)
    Correct. Apply the stretch/compression/reflection (a and k) before the translations (d and c).
  2. B. Horizontal shift left by 3 units (d = -3)
    Not quite. Translations (d and c) come after stretches/compressions/reflections to avoid distorting the graph.
  3. C. Vertical shift up by 4 units (c = 4)
    That's a vertical translation, which should be applied last, not first.
  4. D. Horizontal stretch by factor 1 (k=1 does nothing special)
    While k=1 means no horizontal stretch, the question is about the order. The correct first step is to handle a and k.

Q2. Write f(x) = 8*(0.5x+1)^3 - 3 in the standard transformation form a(k(x-d))^n + c.

errorId: err-poly-k-factor | Bloom: apply | Scaffold: L2

Achievement: Application | Action: apply | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: When given (0.5x+1)^3, students may think d=1 and k=0.5 incorrectly, instead of rewriting as (0.5(x+2))^3.

Remediation → err-poly-k-factor | Retest → err-poly-k-factor

  1. ✓ A. f(x) = 8*(0.5(x+2))^3 - 3, a=8, k=0.5, d=-2, c=-3
    Correct. Factor 0.5 from (0.5x+1) to get 0.5(x+2), so k=0.5, d=-2.
  2. B. f(x) = 8*(0.5x+1)^3 - 3, a=8, k=1, d=-1, c=-3
    This does not factor k out. When k ≠ 1, you must rewrite (0.5x+1) as 0.5(x+2) to identify d correctly.
  3. C. f(x) = 8*(0.5(x+1))^3 - 3, a=8, k=0.5, d=-1, c=-3
    Almost, but (0.5x+1) factored gives 0.5(x+2), not 0.5(x+1). Check by redistributing: 0.5(x+1)=0.5x+0.5, not 0.5x+1.
  4. D. f(x) = 8*(0.5(x-2))^3 - 3, a=8, k=0.5, d=2, c=-3
    The sign of d is wrong. (0.5x+1) = 0.5(x+2) means d = -2 (since x - (-2) = x+2).

补救模块

err-poly-trans-order

Students think the order of transformations can be applied arbitrarily, but actual order matters because translations shift the graph after stretches/compressions, changing the effect.

Explain: When graphing a polynomial in the form a(k(x-d))^n + c, apply stretches/compressions/reflections (a and k) first, then translations (d and c). This order ensures the graph is correctly scaled before shifting.

Example: Consider f(x) = 8*(0.5x+1)^3 - 3. Factor: (0.5x+1) = 0.5(x+2), so f(x)=8*(0.5(x+2))^3 -3. Apply a=8 (vertical stretch) and k=0.5 (horizontal stretch by 2) first, then shift left 2 (d=-2) and down 3 (c=-3).

err-poly-k-factor

The student incorrectly assumes that the coefficient inside the parentheses directly gives k and the constant term gives d, without factoring out the coefficient of x. For example, they might set k=1 and d=-1 for (0.5x+1) instead of correctly factoring to get k=0.5 and d=-2.

Explain: When a polynomial transformation is given as a*(kx + b)^n + c, you must rewrite it as a*(k(x - d))^n + c by factoring k out of the expression kx + b. This gives the correct horizontal stretch/compression factor k and the horizontal shift d. Remember: kx + b = k(x + b/k). So d = -b/k. Always check that k is factored out completely before reading off d.

Example: Take f(x) = 8*(0.5x+1)^3 - 3. Factor 0.5 from the parentheses: 0.5x+1 = 0.5(x+2). So the function becomes f(x) = 8*(0.5(x+2))^3 - 3. Thus a=8, k=0.5, d=-2, c=-3. If you didn't factor, you might think k=1 and d=-1, which would be wrong.

err-poly-verify-root

Students think that if a candidate root satisfies the conditions of the Integral Zero Theorem (divides the constant term) or Rational Zero Theorem (divisor of constant term over divisor of leading coefficient), then it is automatically a root. They skip the verification step of substituting back to check f(root)=0.

Explain: The Integral Zero Theorem and Rational Zero Theorem only give a list of possible roots. To confirm whether a candidate is an actual root, you must substitute it into the original polynomial and verify that the result is zero. Only those values that satisfy f(x)=0 are true roots.

Example: For 4x^3 - 12x^2 - x + 3 = 0, possible rational roots include ±1, ±3, ±1/2, ±3/2, ±1/4, ±3/4. Testing x=3: 4(27)-12(9)-3+3 = 108-108-3+3=0, so x=3 is a root. Testing x=1: 4-12-1+3=-6, not zero, so 1 is not a root despite being a divisor of the constant term.

err-poly-rational-zero

The student may only consider divisors of the constant term and forget that the denominator must be a divisor of the leading coefficient, or may include fractions not in lowest terms.

Explain: The Rational Zero Theorem says that any rational root of a polynomial with integer coefficients is of the form p/q, where p is a factor of the constant term and q is a factor of the leading coefficient. Both p and q must be considered, and the fraction must be in lowest terms.

Example: For 4x^3 - 12x^2 - x + 3 = 0, constant term = 3, leading coefficient = 4. Factors of 3: ±1, ±3. Factors of 4: ±1, ±2, ±4. Possible p/q: ±1/1, ±3/1, ±1/2, ±3/2, ±1/4, ±3/4. After testing, the actual roots are x=3, x=1/2, x=-1/2.
