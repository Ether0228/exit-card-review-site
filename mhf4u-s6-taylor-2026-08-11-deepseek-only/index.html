Q1. A circle has radius r = 2.5 cm and arc length s = 5 cm. What is the central angle θ in degrees?

errorId: err-radian-degree-confusion | Bloom: apply | Scaffold: L2

Achievement: Application | Action: apply | OSSD: Demonstrate an understanding of the meaning and application of radian measure.

Official: B1 | Node: MHF4U-B-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Confusing radian measure with degrees, leading to incorrect unit labels or conversion.

Remediation → err-radian-degree-confusion | Retest → err-radian-degree-confusion

  1. ✓ A. 114.6°
    Correct! First θ = s/r = 2 rad, then convert to degrees: 2 * 180/π ≈ 114.6°.
  2. B. 2.0°
    You computed θ in radians but forgot to convert to degrees. The radian value is 2.0 rad, not 2.0°.
  3. C. 200°
    200° is the value from a different example in class. Here, the given numbers lead to a different result.
  4. D. 0.5°
    You may have inverted the formula (r/s) or confused the conversion. Use θ = s/r, then convert.

    补救模块

    err-radian-degree-confusion

    The student treats the numeric result of the arc length formula s = rθ as automatically in degrees, not realizing that θ must be in radians for the formula to work. This leads to missing the conversion from radians to degrees.

    Explain: The arc length formula s = rθ only works when θ is measured in radians. Radians and degrees are two different units for measuring angles. When you use s = rθ and solve for θ, you get the angle in radians. To express that angle in degrees, multiply by 180/π. If an angle is given in degrees, you must convert it to radians first by multiplying by π/180 before using it in the formula.

    Example: For a circle with r = 2.5 cm and s = 5 cm, first find θ in radians: θ = s/r = 5/2.5 = 2.0 rad. Then convert to degrees: 2.0 × 180/π ≈ 114.6°. Conversely, if you are given θ = 200°, convert to radians first: 200° × π/180 = 10π/9 rad. Then s = 2.5 × 10π/9 = 25π/9 cm ≈ 8.7 cm.

    err-arc-length-formula-inversion

    The student thinks that because arc length is found by multiplying r and θ, the inverse operations must also involve multiplication, so they solve for r or θ by multiplying the two known values instead of dividing by the known variable.

    Explain: The arc length formula is s = rθ, where r is the radius, θ is the central angle in radians, and s is the arc length. To solve for the radius, divide both sides by θ: r = s/θ. To solve for the angle, divide both sides by r: θ = s/r. A common mistake is to invert the formula, for example writing r = sθ, which gives the wrong units and an incorrect value. Always isolate the unknown by dividing, not multiplying.

    Example: If r = 2.5 cm and s = 5 cm, then θ = s/r = 5/2.5 = 2.0 rad. Converting to degrees: θ = 2.0 × (180/π) ≈ 114.6°. An inverted solution might set θ = 5 × 2.5 = 12.5 rad, which is wrong and far too large.

    err-sinusoidal-parameter-sign

    The student incorrectly interprets the sign of the horizontal shift parameter in a sinusoidal function. They think t - 116 means a left shift, or they confuse amplitude sign with the phase shift.

    Explain: In a sinusoidal function written as y = A sin(k(x - d)) + C, the parameter d controls horizontal shift. A positive d shifts the graph d units to the right (because x - d = 0 at x = d), while a negative d shifts it left. A negative A reflects the graph across the midline, but does not change the midline or the phase shift.

    Example: In the Hamilton temperature model T(t) = 13.35 sin(2π/365 (t - 116)) + 8.55, d = 116, so the graph shifts 116 days to the right. If the equation were (t + 116), the shift would be 116 days to the left. The amplitude 13.35 and midline 8.55 remain unchanged.

    err-sinusoidal-period-calculation

    The period is the time for one complete cycle. Students often mix up the frequency coefficient k with the period, or confuse the period with the phase shift. In y = A sin(k(t-d)) + C, the period is found by dividing 2π by k — not by reading k directly.

    Explain: For a sinusoidal function in the form y = A sin(k(t-d)) + C, the period is always 2π/k. The coefficient k is the frequency (how many cycles per unit time), not the period. For example, in the Hamilton temperature model T(t) = 13.35 sin(2π/365 (t-116)) + 8.55, the value k = 2π/365. To find the period, compute 2π ÷ (2π/365) = 365 days. The 116 is the horizontal shift, 13.35 is amplitude, and 8.55 is the midline — none of these tell you the period.

    Example: For the owl population O(t) = 100 sin(πt/12) + 1000, k = π/12. The period is 2π/(π/12) = 24 months. The same k appears in the mouse model M(t) = 4000 cos(πt/12) + 20000, so that population also has a period of 24 months.

    err-application-formatting

    The student thinks that computing a numerical answer is sufficient and doesn't realize that application problems require a clear concluding sentence and correct set notation for domain/range.

    Explain: In application problems, you must communicate your answer clearly. This means you always include a 'therefore' statement that states the result in context, and if you provide a domain or range, you use set notation with the correct symbols. For example, instead of just writing a number, say 'Therefore, the temperature on day 200 is approximately 21.8°C.' For a domain over one year, write {t ∈ ℝ | 0 ≤ t ≤ 365}.

    Example: For the Hamilton temperature model T(t) = 13.35 sin(2π/365 (t-116)) + 8.55, to find T(200): T(200) = 13.35 sin(2π/365 (200-116)) + 8.55 ≈ 21.8°C. Then add: Therefore, the temperature on day 200 is approximately 21.8°C. If asked for the range, use the midline 8.55 and amplitude 13.35: temperatures go from 8.55 - 13.35 = -4.8 to 8.55 + 13.35 = 21.9, so range is {T ∈ ℝ | -4.8 ≤ T ≤ 21.9}.
