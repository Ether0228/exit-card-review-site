Q1. For the function f(x) = x², which of the following correctly describes its range?

errorId: err-domain-range-confusion | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Students may think the domain of x² is y≥0 (confusing range with domain) or include negative x values incorrectly.

Remediation → err-domain-range-confusion | Retest → err-domain-range-confusion

  1. A. All real numbers (x ∈ ℝ)
    This describes the domain, not the range. The range of x² is y ≥ 0.
  2. ✓ B. y ≥ 0
    Correct. The output of x² is always non-negative.
  3. C. y > 0
    Close, but x² can equal 0 (when x=0), so the correct inequality is y ≥ 0, not y > 0.
  4. D. y ≤ 0
    x² gives non-negative outputs, so the range is y ≥ 0, not y ≤ 0.

Learning Goal: lg-2

Misconception: Students may try to solve for y before swapping x and y, or incorrectly isolate y.

Remediation → err-inverse-swap-mistake | Retest → err-inverse-swap-mistake

    Rubric: Step 1: Write f(x) as y = 3x + 1. Step 2: Swap x and y: x = 3y + 1. Step 3: Solve for y: y = (x - 1)/3. Final answer: f⁻¹(x) = (x - 1)/3. Full marks require correct swap and solve.

    Sample: y = 3x + 1, swap: x = 3y + 1 → 3y = x - 1 → y = (x - 1)/3, so f⁻¹(x) = (x - 1)/3.

    补救模块

    err-domain-range-confusion

    Students confuse which set is domain vs range or use incorrect notation.

    Explain: The domain of a function is the set of all possible input values (x), while the range is the set of all possible output values (y). For example, for y=x², the domain is all real numbers (x∈ℝ) because any x can be squared. The range is y≥0 because squares are never negative. Notation: use set-builder like {x|x∈ℝ} or interval like (-∞,∞).

    Example: For f(x)=x², domain: x∈ℝ, range: y≥0. In interval notation: domain (-∞,∞), range [0,∞).

    err-inverse-swap-mistake

    Students forget to swap x and y before solving for the inverse, or incorrectly manipulate the equation after swapping.

    Explain: To find the inverse of a function f(x), first replace f(x) with y. Then swap the variables x and y. Finally, solve the resulting equation for y. The result is the inverse function, denoted f^{-1}(x). Remember: the inverse swaps the input and output roles.

    Example: f(x)=3x+1 → y=3x+1 → swap x and y: x=3y+1 → solve for y: 3y=x-1 → y=(x-1)/3 → f^{-1}(x)=(x-1)/3

    err-notation-open-closed

    Students often confuse open and closed brackets: they may think an open bracket includes the endpoint or a closed bracket excludes it, or they may not recall the rule at all.

    Explain: In interval notation, brackets indicate whether an endpoint is included or excluded. A closed bracket [ or ] means the endpoint is included (≤ or ≥). An open bracket ( or ) means the endpoint is excluded (< or >). Always read from left to right: the first symbol indicates the start, the second indicates the end.

    Example: The interval (3, 5] includes all numbers greater than 3 (but not 3) up to and including 5. So 4 is in the set, but 3 is not. In set-builder notation, this is {x | 3 < x ≤ 5}.
