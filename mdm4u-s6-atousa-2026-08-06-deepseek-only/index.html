Q1. Using Dataset 1 (min=10, Q1=26, median=34, Q3=44, max=47), what is the IQR and the lower and upper outlier boundaries using the 1.5*IQR rule?

errorId: err-boxplot-iqr-boundaries | Bloom: apply | Scaffold: L2

Achievement: Application | Action: apply | OSSD: Analyse, interpret, and draw conclusions from one-variable data using numerical

Official: D1 | Node: MDM4U-D-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-boxplot

Misconception: Subtracts 1.5*IQR from Q3 instead of Q1, or mixes up Dataset 1 and Dataset 2 values.

Remediation → err-boxplot-iqr-boundaries | Retest → err-boxplot-iqr-boundaries

  1. ✓ A. IQR = 18; lower boundary = -1, upper boundary = 71
    Correct! IQR = 44 - 26 = 18; lower fence = 26 - 1.5*18 = -1; upper fence = 44 + 1.5*18 = 71.
  2. B. IQR = 18; lower boundary = 26, upper boundary = 44
    The boundaries are not simply Q1 and Q3; they must be extended by 1.5 times the IQR. Here, that gives -1 and 71.
  3. C. IQR = 10; lower boundary = 4, upper boundary = 44
    Those are the values from Dataset 2. Recalculate using Dataset 1: Q3-Q1 = 44-26 = 18.
  4. D. IQR = 18; lower boundary = -27, upper boundary = 71
    Check the lower fence formula: it's Q1 - 1.5*IQR, not (Q1 - Q3) - 1.5*IQR.

Q2. In a box plot, the whiskers extend from the box to the most extreme data point within the fences. If a data point lies exactly at the upper fence value (Q3 + 1.5*IQR), how is it represented?

errorId: err-boxplot-threshold-mistake | Bloom: understand | Scaffold: L2

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Analyse, interpret, and draw conclusions from one-variable data using numerical

Official: D1 | Node: MDM4U-D-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-boxplot

Misconception: Believing that any point whose value equals a computed fence should be plotted as an outlier.

Remediation → err-boxplot-threshold-mistake | Retest → err-boxplot-threshold-mistake

  1. A. As an outlier with a special symbol (e.g., asterisk)
    Points at the exact fence are not outliers—they are the farthest allowed within the whisker.
  2. ✓ B. As the endpoint of the upper whisker
    Yes! The fence is the boundary; a point at that value is still inside and becomes the end of the whisker.
  3. C. Inside the box, because it equals Q3 + something
    The box represents the IQR (Q1 to Q3). The fence is far outside the box, so this point is at the whisker's tip.
  4. D. It is omitted from the plot
    All data within the fences must appear in the plot; no data is omitted unless it exceeds the fences.

Q3. When constructing a scatter plot, which variable is conventionally placed on the x-axis?

errorId: err-scatter-axes-swap | Bloom: remember | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Analyse, interpret, and draw conclusions from two-variable data using numerical,

Official: D2 | Node: MDM4U-D-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-scatterplot

Misconception: Placing the response variable on the x-axis or choosing the variable with larger values.

Remediation → err-scatter-axes-swap | Retest → err-scatter-axes-swap

  1. ✓ A. The explanatory (independent) variable
    Exactly. The explanatory variable goes on the x-axis.
  2. B. The response (dependent) variable
    The response is plotted on the y-axis, not the x-axis.
  3. C. The variable that was measured first
    Measurement order doesn't determine axis placement; the causal role does.
  4. D. The variable with larger numerical values
    Scale doesn't matter—axis placement is based on the variable's role (explanatory vs. response).

    补救模块

    err-boxplot-iqr-boundaries

    The student confuses the roles of Q1 and Q3. They may think IQR is Q1 - Q3, or they subtract 1.5*IQR from Q3 instead of from Q1, producing incorrect lower fences.

    Explain: A box plot uses the five-number summary: minimum, Q1, median, Q3, maximum. The IQR is always Q3 - Q1, so the bigger quartile minus the smaller quartile. Outlier boundaries are Q1 - 1.5*IQR and Q3 + 1.5*IQR. The lower boundary must be based on Q1, and the upper boundary must be based on Q3.

    Example: Dataset 1: Q1=26, Q3=44. IQR = 44-26 = 18. Lower boundary = 26 - 1.5*18 = -1. Upper boundary = 44 + 1.5*18 = 71. A common mistake is using Q3 for the lower boundary: 44 - 1.5*18, which would place the lower fence above Q1, not below it.

    err-boxplot-threshold-mistake

    The student treats the computed fence values (Q1 - 1.5*IQR and Q3 + 1.5*IQR) as outliers themselves. The fences are only boundary cutoff points; a data value equal to a fence is still considered within the data range and is drawn as the whisker endpoint, not as an outlier.

    Explain: The 1.5*IQR rule creates fences to separate typical values from outliers. The lower fence is Q1 - 1.5*IQR, and the upper fence is Q3 + 1.5*IQR. For Dataset 1, IQR = 44 - 26 = 18, so lower fence = 26 - 1.5*18 = -1 and upper fence = 44 + 1.5*18 = 71. The fences themselves are not data points and are not outliers. If a data value is exactly -1 or exactly 71, it is still within the fences and becomes the end of the whisker. Only values less than -1 or greater than 71 are outliers. Since Dataset 1's minimum is 10 and maximum is 47, no values are beyond the fences, so the plot has no outliers.

    Example: For Dataset 2, IQR = 29 - 19 = 10, so lower fence = 19 - 1.5*10 = 4 and upper fence = 29 + 1.5*10 = 44. The actual minimum is 9 and the actual maximum is 43. Both are inside the fences, so there are no outliers. If a data value were exactly 4, it would equal the lower fence, not be an outlier, and would be the endpoint of the lower whisker.

    err-scatter-axes-swap

    You may have assumed the variable that comes first in the phrase or has smaller numbers goes on the x-axis. In fact, axis placement is determined by the variable's role: the explanatory variable (suspected cause) goes on the x-axis, and the response variable (suspected effect) goes on the y-axis. This convention comes from the research hypothesis, not from the order variables are listed or their magnitudes.

    Explain: A scatter plot always places the explanatory (independent) variable on the x-axis and the response (dependent) variable on the y-axis. The explanatory variable is the suspected cause, and the response variable is the suspected effect. Flipping the axes would distort the visual relationship and make it harder to interpret which variable affects which.

    Example: In a study of how basketball practice hours affect free throw success, practice hours are explanatory and free throw success is response. So practice hours go on the x-axis and free throw success on the y-axis. Similarly, for fertilizer amount → plant height, fertilizer amount is on the x-axis and plant height on the y-axis.

    err-var-id-context

    The student believes certain variables are always explanatory or always response (e.g., 'time' or 'amount' is always explanatory), instead of checking which variable is the suspected cause and which is the effect in the specific study context.

    Explain: In any study, the explanatory (independent) variable is the suspected cause or predictor, and the response (dependent) variable is the possible effect or outcome. These roles are not fixed properties of the variables; they depend on the research question. To decide, ask: 'Which variable is being used to explain or predict the other?' and 'Which one changes as a result?' The variable that plays the role of the suspected cause is explanatory; the variable that is the outcome is response.

    Example: From the lesson: 'fertilizer amount → plant height.' The research hypothesis is that fertilizer amount explains plant height, so fertilizer amount is explanatory and plant height is response. But if a different study asked whether plant height predicts how much fertilizer is needed, then plant height would be explanatory and fertilizer amount would be response—the context changes the roles.

    err-correlation-misclassify

    The student confuses strength with direction or pattern: they think 'strong' means the line points upward or is steep, and they treat any close relationship as linear even when the points follow a curve. Strength is about how tightly points cluster around a trend line, direction is about upward or downward slope, and pattern must be straight for a linear label.

    Explain: Correlation classifies two-variable relationships using three separate features: pattern, direction, and strength. Pattern asks whether the relationship is linear, non-linear, or none. Direction asks whether the variables tend to increase together (positive) or whether one increases while the other decreases (negative). Strength asks how closely the points cluster around a trend line: strong, moderate, weak, or none. These features are independent. A strong correlation can be positive or negative; a weak correlation can still be positive. Also, the word 'linear' only applies when the points follow a straight-line pattern. A tight U-shaped curve is non-linear, even though the pattern is very consistent.

    Example: Study hours and exam score often show a positive linear correlation: as study hours increase, exam score tends to increase. If the points are tightly clustered around a straight upward-sloping line, the correlation is strong. If the points are more spread out but still generally rise, the strength is moderate or weak. The positive direction comes from the upward slope, not from how strong the clustering is. Similarly, excess speed and traffic fine amount show a positive direction because the fine increases with excess speed, but if the points are widely scattered, the strength would be weak or none, not strong.
