补救模块

err-vertical-line-test-circle

Student thinks a circle passes the vertical line test because it is a closed curve.

Explain: The vertical line test checks if each x-value corresponds to exactly one y-value. A vertical line through most points of a circle will intersect it at two points, meaning one x gives two y-values. This violates the definition of a function, so a circle is not a function.

Example: Consider the circle x²+y²=1. At x=0, you get y=1 and y=-1. A vertical line at x=0 crosses the circle at (0,1) and (0,-1), failing the test.

err-domain-range-confusion

The student mistakenly swaps the definitions of domain and range, believing domain refers to y-values (outputs) and range refers to x-values (inputs).

Explain: Domain is the set of all possible input values (x) for a function. Range is the set of all possible output values (y). For a function like f(x)=x^2, the domain is all real numbers because you can square any real number. The range is y≥0 because squaring a real number never gives a negative result.

Example: Consider f(x)=x^2. Domain: x∈R (all real numbers). Range: y≥0 (all non-negative real numbers).

err-reciprocal-function-graph

Student does not recognize the graph of f(x)=1/x as a reciprocal function.

Explain: A reciprocal function is one where the output is the reciprocal of the input, written as f(x)=1/x. Its graph has two separate branches (one in quadrant I and one in quadrant III) and never touches the x-axis or y-axis because division by zero is undefined and the function approaches but never reaches zero.

Example: f(x)=1/x is the basic reciprocal function. For x=2, f(2)=1/2; for x=-3, f(-3)=-1/3.

err-exponential-log-inverse

Student fails to understand that exponential and logarithmic functions are inverses.

Explain: Exponential and logarithmic functions are inverses of each other. This means that if f(x)=a^x, then its inverse is g(x)=log_a(x). Applying one after the other returns the original input: f(g(x))=x and g(f(x))=x.

Example: f(x)=2^x and g(x)=log_2(x) are inverses. f(g(8))=2^{log_2(8)}=8 and g(f(3))=log_2(2^3)=3.

err-handwritten-submissions

Student thinks typed math submissions are acceptable.

Explain: All math assessments must be handwritten. Typed submissions receive zero. You must also sign the academic integrity agreement before grading.

Example: A student types their solution using a math editor and submits it. The submission receives a grade of zero because it is not handwritten.
