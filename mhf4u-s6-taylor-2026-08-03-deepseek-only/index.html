Q1. Which exponential equation is equivalent to log₅(25)=2?

errorId: err-ConvertExpLog-misidentifyBaseExponent | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: Convert between exponential and logarithmic forms accurately.

Misconception: Misidentifying the base and exponent when converting between forms.

Remediation → err-ConvertExpLog-misidentifyBaseExponent | Retest → err-ConvertExpLog-misidentifyBaseExponent

  1. ✓ A. 5² = 25
    Correct. The base of the log becomes the base of the exponent, the result becomes the exponent, and the number inside the log becomes the result.
  2. B. 2⁵ = 25
    You swapped the base and the exponent. Remember: log_b(a)=c means b^c = a. Here b=5, c=2, a=25, not 2^5=25.
  3. C. 25² = 5
    You confused the positions. The base is 5, the exponent is 2, and the result is 25. The correct form is 5²=25.
  4. D. 5^25 = 2
    The exponent and result are swapped. The log result (2) is the exponent, so the exponential form is 5²=25.

Q2. Evaluate log₂(8) without a calculator.

Learning Goal: Evaluate logarithms without a calculator using exponential form.

  1. ✓ A. 3
    Correct. Rewriting as 2ˣ=8, since 2³=8, x=3.
  2. B. 16

  4. D. Cannot determine without calculator

Q3. Solve: log₂(x+1) = 3

Achievement: Application | Action: apply | OSSD: Solve exponential and simple logarithmic equations in one variable algebraically

Official: A3 | Node: MHF4U-A-OE03 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Misconception: Incorrectly applying log properties such as dropping log without converting to exponential.

Remediation → err-SolveExpLogEq-dropLogIncorrectly | Retest → err-SolveExpLogEq-dropLogIncorrectly

  1. ✓ A. x = 7
    Correct. Rewrite as 2³ = x+1 → 8 = x+1 → x=7.
  2. B. x = 5
    You might have subtracted 1 first without converting from log form. Convert to exponential first: base 2 raised to power 3 equals x+1.
  3. C. x = 8
    You might have set x+1=3 directly. Remember, the log equation log_b(y)=c means b^c = y.
  4. D. x = 2
    You may have divided or misapplied. Use the definition: log₂(x+1)=3 → 2³ = x+1.

补救模块

err-ConvertExpLog-misidentifyBaseExponent

The student does not understand which numbers are the base, exponent, and result in a logarithm, confusing the argument with the exponent and the log value with the result.

Explain: A logarithm tells you what exponent you need to put on a base to get another number. The equation log_b(a) = c means 'the base b raised to the exponent c gives the result a.' So you can rewrite it as b^c = a. To convert, keep the base the same, put the log value (c) as the exponent, and set the result equal to the number inside the log (a).

Example: For log₅(25)=2, the base is 5, the exponent is 2, and the result is 25. In exponential form, this is 5²=25. Notice the base 5 stays the base, the exponent 2 is the log value, and 25 is the input of the log.

err-EvalLogNoCalc-forgetRewriteExponential

The student treats logarithms as a calculator operation rather than a question in exponential form. They forget that log_b(a)=c is equivalent to b^c=a, so without a calculator they don't know where to start and may attempt guesswork or give up.

Explain: Remember: a logarithm is an exponent. log_b(a) asks 'what power of b gives a?' Rewrite the log as an exponential equation: log_b(a)=c means b^c=a. Then find c by using powers you know. You do not need the calculator's log key; you just need to recognize the inverse relationship between exponential and logarithmic forms.

Example: Evaluate log₂(8). Let log₂(8)=c. Rewrite as 2^c=8. Since 2³=8, c=3. So log₂(8)=3.

err-SolveExpLogEq-dropLogIncorrectly

The student treats the log as a removable label rather than the exponent. For example, from log₂(x+1)=3 they write x+1=3. The log function is not 'cancelled' when it is on only one side of the equation.

Explain: A logarithm is an exponent. The equation log_b(A)=C means that the base b raised to the power C equals A. So when you see log₂(x+1)=3, you must rewrite it as 2³=x+1. Dropping the log without rewriting is the most common error. Also, log(a+b) is not log(a)+log(b); exponent rules apply to products/quotients, not sums.

Example: Solve log₂(x+1)=3. Incorrect: x+1=3 → x=2. Correct: Rewrite in exponential form: 2³=x+1 → 8=x+1 → x=7. Check: log₂(7+1)=log₂(8)=3 because 2³=8.

err-EstimateLogGuessCheck-interpolateLinearly

The student believes the logarithmic function is linear, so equal changes in x produce equal changes in y. This leads to estimates like log₂10 ≈ 3.25, but the actual value is about 3.32. The student does not verify the estimate by converting back to exponential form or by using guess-and-check.

Explain: A logarithm is an exponent: log₂(x) is the number y such that 2^y = x. The graph of y = log₂(x) is a curve, not a straight line. As x increases, the log grows more and more slowly. Therefore, you cannot linearly interpolate between two known points. For example, log₂8 = 3 and log₂16 = 4. Linear interpolation would suggest log₂10 = 3 + (10−8)/(16−8) = 3.25. But check: 2^3.25 = 2^3 × 2^0.25 = 8 × 1.189 = 9.51, not 10. To estimate accurately, use guess-and-check with powers: try y = 3.3 → 2^3.3 = 8 × 2^0.3 ≈ 8 × 1.23 = 9.85, too low; try y = 3.32 → 2^3.32 ≈ 8 × 1.25 = 10.0. So log₂10 ≈ 3.32. Always validate your estimate by checking the exponential form.

Example: Estimate log₂(10). Since 2^3 = 8 and 2^4 = 16, log₂10 is between 3 and 4. Guess-and-check: 2^3.3 = 2^3 · 2^0.3 ≈ 8 · 1.23 = 9.85 (too low). 2^3.32 ≈ 8 · 1.25 = 10.0 (close). Therefore log₂10 ≈ 3.32. Note: linear interpolation gave 3.25, which is too low because the log curve is not linear.

err-KeyFeaturesLog-confuseDomain

The student confuses the domain of a logarithmic function with that of an exponential function, or forgets that the argument of a logarithm must be strictly positive. They may include zero or negative numbers in the domain, and may fail to shift the domain correctly for transformed functions such as f(x)=log_b(x-h).

Explain: For a logarithmic function y = log_b(x), the input x (the argument) must be greater than 0 because b^y is always positive for any real y (when b > 0 and b ≠ 1). So the domain of the parent function is (0, ∞). For a transformed function like f(x) = log_b(x - h), set the argument (x - h) > 0. Solving gives x > h, so the domain is (h, ∞). The vertical asymptote is at x = h, where the argument equals zero.

Example: For f(x) = log₂(x + 1), set x + 1 > 0 → x > -1. Therefore the domain is (-1, ∞), and the vertical asymptote is x = -1.

err-InverseExpLog-swapDomainRangeIncorrectly

The student does not recognize that for an inverse function, the domain and range are exchanged. They may think that both functions have the same domain and range, or they swap them the wrong way (e.g., saying the log function has domain all real numbers), and they often omit the symmetry line y=x.

Explain: For an inverse function, the domain and range are swapped. For y=2^x, the domain is all real numbers and the range is (0, ∞). Since y=log₂x is the inverse, its domain is (0, ∞) (the range of the exponential) and its range is all real numbers (the domain of the exponential). The graphs of the two functions are mirror images across the line y=x.

Example: y=2^x: domain = {x∈R}, range = {y>0}. y=log₂x: domain = {x>0}, range = {y∈R}. On a graph, each point (a,b) on y=2^x corresponds to point (b,a) on y=log₂x, reflecting across y=x.

err-GraphLogTransform-misapplyMapping

The student applies the horizontal transformation in the same direction as the sign inside the argument, forgetting that mapping notation uses x' = x - h. They also fail to track the vertical asymptote shift because they don't set the argument equal to zero (x+1=0 → x=−1). This often leads to adding 1 to x‑values when they should subtract 1.

Explain: Mapping notation tells you how each point on the parent graph moves. For y = log₂(x - h) + k, points (x,y) move to (x + h, y + k). The h is the horizontal shift. Important: if the function is log₂(x + 1), rewrite it as log₂(x − (−1)), so h = −1. That means every parent point moves 1 unit left. The vertical asymptote also moves from x=0 to x=−1. Many students see '+1' and shift right; remember the formula: 'x minus h inside, so add h to x in mapping.'

Example: Graph f(x)=log₂(x+1). Parent points: (1,0), (2,1), (4,2). Since h=−1, mapping: (x,y)→(x−1,y). So: (1,0)→(0,0), (2,1)→(1,1), (4,2)→(3,2). The vertical asymptote x=0 becomes x=−1. Check: f(0)=log₂(1)=0, f(1)=log₂(2)=1, f(3)=log₂(4)=2. The graph is the parent shifted left 1.
