补救模块

err-rational-va-horizontal-mixup

Students often mix up vertical and horizontal asymptotes. They may think that the horizontal asymptote is found from the denominator root, or that the vertical asymptote is a horizontal line.

Explain: For Type 1 rational functions f(x)=a/(cx+d), the vertical asymptote is found by setting the denominator equal to zero: cx+d=0, so x = -d/c. The horizontal asymptote is always y=0, because as x becomes very large or very small, the fraction approaches 0. These are different: vertical is a vertical line, horizontal is a horizontal line.

Example: For f(x)=3/(2x-4), set denominator 2x-4=0 → x=2 is vertical asymptote. Horizontal asymptote is y=0.

err-rational-intercept-x

The student may think that rational functions always have an x-intercept, or may confuse the method for finding x-intercepts with finding vertical asymptotes. For Type 1 rational functions of the form f(x)=a/(cx+d) with a constant non-zero, the numerator never equals zero, so there is no x-intercept.

Explain: For a rational function f(x)=p(x)/q(x), x-intercepts occur when p(x)=0 (provided q(x)≠0). In Type 1 rational functions, f(x)=a/(cx+d), the numerator a is a non-zero constant. Since a≠0, it can never equal zero. Therefore, the function has no x-intercept. The graph does not cross the x-axis.

Example: Consider f(x)=4/(2x-5). Set numerator 4=0? Impossible. So no x-intercept. The y-intercept is found by setting x=0: f(0)=4/(2*0-5)=4/(-5)=-0.8.

err-rational-domain-all-reals

The student thinks the domain of a rational function is all real numbers without excluding values that make the denominator zero.

Explain: A rational function is undefined when the denominator equals zero because division by zero is not allowed. Therefore, the domain must exclude any value of x that makes the denominator zero. To find these excluded values, set the denominator equal to zero and solve for x.

Example: Consider f(x) = 4/(2x-5). Set 2x-5=0 → x=2.5. The function is undefined at x=2.5. So the domain is all real numbers except 2.5: {x ∈ ℝ | x ≠ 2.5}.
