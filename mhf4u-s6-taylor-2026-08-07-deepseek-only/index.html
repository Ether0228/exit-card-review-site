Learning Goal: lg-1

Misconception: Student thinks cosine is positive in QIII or forgets to apply the CAST rule.

Remediation → err-exactval-sign | Retest → err-exactval-sign

  1. A. Positive, because cosine is the x-coordinate
    Cosine is the x-coordinate, but in quadrant III the x-coordinate is negative.
  2. ✓ B. Negative, since 5π/4 is in quadrant III where cosine is negative
    Correct. 5π/4 is in quadrant III, and the CAST rule makes cosine negative.
  3. C. Zero, because the angle lies on an axis
    5π/4 is not on an axis; it lies in quadrant III.
  4. D. Positive, because 5π/4 is in quadrant II
    5π/4 is not in quadrant II; it is in quadrant III.

补救模块

err-exactval-sign

The student does not use the quadrant location to determine the correct sign of the trigonometric value, often giving a positive result when the ratio is negative or vice versa.

Explain: Before evaluating an exact trig ratio, locate the angle in its quadrant. Then use the CAST rule to decide which ratios are positive there. In Quadrant I all are positive, in Quadrant II sine (and cosecant) are positive, in Quadrant III tangent (and cotangent) are positive, and in Quadrant IV cosine (and secant) are positive. For example, 5π/4 is in Quadrant III. The related acute angle is π/4, so the reference value is 1/√2, but because x is negative in Quadrant III, cos(5π/4) = –1/√2.

Example: cos(5π/4): 5π/4 is in QIII. Using the π/4 special triangle, the absolute value is 1/√2. In QIII, cosine (the x-coordinate) is negative, so cos(5π/4) = –1/√2.

err-exactval-triangle

The student confuses which special triangle corresponds to which reference angle, often mixing up π/4 and π/6, or the ratios of the 1-√3-2 triangle with the 1-1-√2 triangle.

Explain: Exact trigonometric values come from two special right triangles: 1-1-√2 (for angles of π/4) and 1-√3-2 (for angles of π/6 and π/3). For any angle, first find the related acute angle—the angle between the terminal arm and the x-axis. Then match that acute angle to the correct special triangle. For example, π/6 always uses the 1-√3-2 triangle, where opposite = 1, adjacent = √3, hypotenuse = 2. If you use the wrong triangle, you will get the wrong ratio even if you correctly apply the sign from CAST.

Example: To find csc(11π/6): 11π/6 is in quadrant IV, so the related acute angle is 2π – 11π/6 = π/6. Since π/6 uses the 1-√3-2 triangle, sin(π/6) = 1/2, so csc(π/6) = 2. Because sine is negative in QIV, csc(11π/6) = –2.

err-graph-asymptote

Reciprocal trig graphs are drawn by looking at zeros of the wrong base function; the student needs to recall csc = 1/sin and sec = 1/cos.

Explain: A reciprocal trig graph has a vertical asymptote wherever its base function has an x-intercept. For y = csc x, since csc x = 1/sin x, the graph is undefined at sin x = 0, so vertical asymptotes occur at x = 0, π, and every integer multiple of π. For y = sec x, the base function is cos x, so asymptotes occur where cos x = 0. For y = cot x, cot x = cos x/sin x, so its asymptotes also occur at sin x = 0.

Example: At x = 0, sin(0) = 0, so csc(0) = 1/0 is undefined. Therefore, y = csc x has a vertical asymptote at x = 0. Check: if you used cos x = 0, you would expect an asymptote at x = π/2, but csc(π/2) = 1, which is a defined point, so that can't be correct.

err-transform-order

Applying translations before stretches/reflections when transforming function points.

Explain: For a sine or cosine function written as f(x) = a·sin[k(x–d)] + c, the parameters a and k are stretches/reflections. They must be applied first because they change the shape and scale of the graph. The parameters d and c are translations, which slide the graph afterward. If you translate first, the stretch/compression will also affect your shift, so the graph ends up in the wrong position.

Example: For f(x)=3sin[2(x+π/6)]–1: first apply the vertical stretch by factor 3 and the horizontal compression by factor 1/2 (period π, because period = 2π/|k| with k=2). Then apply the horizontal shift left by π/6 (d=–π/6) and the vertical shift down by 1 (c=–1).

err-transform-shift-direction

The student sees a plus sign in the argument x+π/6 and assumes the graph shifts to the right. For a sine/cosine function written as a·sin[k(x–d)]+c, the horizontal shift is read from the value of d, so x+π/6 must be rewritten as x–(–π/6), making d=–π/6, which means a left shift by π/6.

Explain: When analyzing transformations of sine and cosine functions, first rewrite the function in the form f(x)=a·sin[k(x–d)]+c or f(x)=a·cos[k(x–d)]+c. The value of d controls the horizontal shift. If the argument is x+π/6, rewrite it as x–(–π/6). Therefore d=–π/6, and the graph shifts left by π/6. The visible sign in front of π/6 is the opposite of the direction: a plus sign inside the bracket means a left shift, and a minus sign means a right shift.

Example: In f(x)=3sin[2(x+π/6)]–1, rewrite the inside as 2(x–(–π/6)). So d=–π/6; the graph shifts left π/6, not right. The other parameters are amplitude 3, period π, and vertical shift –1.
