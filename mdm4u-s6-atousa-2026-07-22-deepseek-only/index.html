Learning Goal: lg-1

Misconception: Confusing hypergeometric with binomial when trials are dependent.

Remediation → err-hypergeometric-confuse-binomial | Retest → err-hypergeometric-confuse-binomial

  1. A. Binomial
    This scenario involves draws without replacement, so hypergeometric is correct; binomial applies when draws are independent with replacement.
  2. ✓ B. Hypergeometric
    Correct. Because we draw without replacement, the trials are dependent, and the hypergeometric distribution is appropriate.
  3. C. Uniform
    Uniform distribution would imply all outcomes equally likely, which does not hold here due to sampling without replacement.
  4. D. Poisson
    Poisson distribution is used for count of events in a fixed interval, not for sampling without replacement.

Remediation → err-hypergeometric-expected-value-formula | Retest → err-hypergeometric-expected-value-formula

    Correct. E(X) = r * (A/(A+B)) = 5 * (8/12) ≈ 3.33.

补救模块

err-hypergeometric-confuse-binomial

The student confuses hypergeometric and binomial distributions, treating dependent draws (without replacement) as independent (with replacement), which changes the probability structure.

Explain: Hypergeometric distribution applies when selections are made without replacement, making trials dependent. Binomial applies when selections are with replacement or trials are independent. For hypergeometric, the probability of success changes after each draw because the population size decreases. For binomial, the probability stays constant.

Example: Selecting 3 people from a group of 8 men and 10 women to form a committee. The number of women selected follows a hypergeometric distribution because once a person is chosen, they are not replaced. If we were to select with replacement, it would be binomial.

err-hypergeometric-wrong-success-count

Students often confuse which category is considered 'success' and which is 'failure', or they mistakenly use the total population size as the success count. This leads to incorrect probability calculations.

Explain: In hypergeometric problems, 'success' means the outcome you are counting. For example, if we want the number of adults in a selection, adults are successes. The parameter A is the total number of successes in the population, and B is the total number of failures (the rest). Always identify A as the count of the category you are interested in.

Example: In a group of 12 people, 8 are adults and 4 are children. You randomly select 5 without replacement. Let X = number of adults. Here, adults are successes, so A=8, B=4, total N=12. The formula uses A and B.

err-hypergeometric-x-outside-range

The student thinks any value from 0 to the number of draws is possible, ignoring the constraint that successes cannot exceed those present in the population.

Explain: In hypergeometric distribution, the number of successes x cannot exceed the smaller of A (total successes) and r (number of draws). Also, x cannot be less than max(0, r - B). For example, with 10 women and 8 men choosing a 3-person committee, x (women) can only be 0, 1, 2, or 3, not 4 or more.

Example: Select 5 candies from a box of 19 (8 yellow, 4 green, 4 purple, 3 red). Success = red (A=3). Draws r=5. Possible x: 0 to 3 (since min(3,5)=3). x=4 is impossible.

err-hypergeometric-combination-formula

Students often confuse combinations (C(n,k)) with permutations (P(n,k)) when setting up the hypergeometric probability formula. They may also incorrectly use addition instead of multiplication in the numerator, or use the wrong denominator.

Explain: In hypergeometric probability, we count the number of ways to choose successes and failures without regard to order. The combination formula C(n,k) = n!/(k!(n-k)!) counts the number of ways to choose k items from n distinct items when order does not matter. In the hypergeometric formula P(X=x) = [C(A,x) * C(B, r-x)] / C(A+B, r), we multiply the combinations for successes and failures because we need both to occur. The denominator is the total number of ways to choose r items from the entire population. Remember: order does not matter, so use combinations, not permutations.

Example: For A=5 successes, B=7 failures, r=4 draws, P(X=2) = [C(5,2)*C(7,2)] / C(12,4). Compute C(5,2)=10, C(7,2)=21, C(12,4)=495, so P = (10*21)/495 = 210/495 ≈ 0.4242.

err-hypergeometric-expected-value-formula

Student expects E(X) = np (binomial) but does not apply hypergeometric expected value calculation which is E(X) = r * (A/(A+B)).

Explain: In a hypergeometric distribution, the expected value is found by multiplying the number of draws (r) by the proportion of successes in the population (A/(A+B)). This is because each draw without replacement is not independent, but the expected number still scales linearly with the proportion. Unlike binomial where E(X)=np, hypergeometric does not assume independence, so the formula is E(X)=r*(A/(A+B)).

Example: Selecting 3 people from 8 men and 10 women, with 'women' as success: A=10, B=8, A+B=18, r=3. So E(X)=3*(10/18)=3*0.5556=1.67.
