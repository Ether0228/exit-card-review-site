Misconception: The learner thinks histograms and bar charts are interchangeable or that the only difference is axis orientation.

Remediation → err-histogram-barchart-confusion | Retest → err-histogram-barchart-confusion

  1. ✓ A. A histogram uses adjacent bars for continuous numerical data; a bar chart uses gaps for categorical data.
    Correct. Histograms display continuous data with no gaps between bars, while bar charts show separate categories with gaps.
  2. B. A histogram has gaps between bars because the data are categorical.
    That describes a bar chart. Histograms use adjacent bars because the data are continuous.
  3. C. A histogram is the same as a bar chart with the X and Y axes swapped.
    Swapping axes does not change the type of graph. Histograms use continuous intervals, not discrete categories.
  4. D. A histogram is only used for categorical data.
    Histograms are for continuous numerical data. Categorical data are shown in bar charts.

补救模块

err-histogram-barchart-confusion

The student confuses histograms with bar charts, thinking they are interchangeable or that the only difference is axis orientation. They do not recognize that histograms use adjacent bars for continuous data while bar charts use gaps for categories.

Explain: A histogram displays continuous numerical data using adjacent bars with no gaps, because data values flow across intervals on a continuous scale. A bar chart displays categorical data with separated bars, because each category is distinct. In a histogram, the x-axis represents continuous intervals (bins) and the y-axis represents frequency (count). In a bar chart, the x-axis represents categories and the y-axis represents count. The key difference: histograms have no gaps; bar charts have gaps.

Example: Look at the two graphs from the diagnostic question. The left graph is a histogram: the x-axis is labeled 'Value' and the bars touch, showing the distribution of scores in intervals like 39.5–47.5. The right graph is a bar chart: the x-axis is labeled 'Category' and the bars are separated, showing counts for distinct categories. Both can show counts, but the type of data is different.

err-histogram-interval-boundaries

The student does not use the .5 boundary offset for integer data, so data points can fall exactly on interval edges and become ambiguous. They may start at the minimum value or at an integer boundary.

Explain: Histograms show continuous intervals, so every data point must belong to exactly one bin. For integer data, set boundaries that end in .5 (e.g., 39.5, 47.5) so no integer lies on an edge. In the exam-score example, min = 41, max = 94, actual range = 53, rounded range = 56, and bin width = 8. The extra range is 3; half of that extra is 1.5. So the first lower boundary is 41 − 1.5 = 39.5. Add the bin width repeatedly to get 47.5, 55.5, 63.5, 71.5, 79.5, 87.5, 95.5.

Example: Question 4 data set: bins [39.5,47.5), [47.5,55.5), [55.5,63.5), [63.5,71.5), [71.5,79.5), [79.5,87.5), [87.5,95.5) with frequencies 3, 4, 3, 3, 6, 3, 3. A score of 41 falls inside the first bin, not on a boundary.

err-histogram-interval-number

They believe any number of intervals is acceptable or that the interval count should equal the number of data points. This causes histograms that either hide distribution features (too few intervals) or fragment the data (too many intervals).

Explain: A histogram shows how continuous data are distributed across equal-width intervals. Using too few intervals hides the shape of the distribution; using too many intervals fragments the data. The recommended number is 5–10 intervals. To find the number of intervals, divide the rounded range by the bin width.

Example: For the exam score dataset: min=41, max=94, actual range=53, rounded range=56, bin width=8. Number of intervals = 56 ÷ 8 = 7. This produces bins [39.5,47.5), [47.5,55.5), ..., [87.5,95.5) with frequencies 3,4,3,3,6,3,3. With 7 intervals, the distribution's shape is clearly visible. Using only 2 intervals would hide distribution features; using 15 intervals would fragment the data into too many small bars.

err-histogram-frequency-count

The student struggles to count data points within histogram intervals correctly, especially when values lie at or near interval boundaries. They may double-count boundary values, omit values that fall near the edge, or lose track when manually tallying a larger data set.

Explain: Once interval boundaries are fixed, counting frequencies must be exact. For each interval written as [L, U), include every data point x where L ≤ x < U. This means the lower boundary L is included and the upper boundary U is excluded. With integer data, boundaries are chosen to end in .5, so no integer data point can land exactly on a boundary. When counting, use a tally system: place one tally mark per data point in its correct interval, then total the tallies. After finishing, check that the sum of all interval frequencies equals the total number of data points.

Example: In the exam-score example, seven intervals run from [39.5,47.5) to [87.5,95.5). The frequency table shows 3, 4, 3, 3, 6, 3, 3. The value 6 in the interval [79.5,87.5) means exactly six scores satisfy 79.5 ≤ score < 87.5. A score cannot be counted in both [79.5,87.5) and [87.5,95.5) because the boundary 87.5 is excluded from the first interval and included in the next.

err-histogram-technology-settings

The student overlooks the required Stat Plot settings and WINDOW parameters, causing the calculator to produce a histogram that is mis-scaled, has incorrect bar widths, or fails to display the correct frequencies.

Explain: When using a TI-83/84 to create a histogram, you must enter the data into L1 (STAT → Edit). Then open the Stat Plot menu (2nd + Y=), select the histogram icon, and set Frequency to 1. This tells the calculator that L1 contains data values, not frequencies. To adjust the scale, you can use ZOOM 9 for auto-scale, or set Xmin and Xscl manually in the WINDOW menu. For integer data, the first interval boundary should end in .5, and Xscl should equal the bin width. If Frequency is not 1 or Xscl is wrong, the histogram will not accurately represent the distribution of the data.

Example: For the exam score data with min 41 and max 94, using 7 intervals gives a rounded range of 56 and a bin width of 8. The first interval boundary should be 39.5. On the TI-84, enter the scores in L1, set Frequency to 1, and either press ZOOM 9 or set Xmin = 39.5 and Xscl = 8 in WINDOW. If you forget Frequency = 1 or set Xscl = 10, the histogram bars will be mis-aligned and the frequencies will be incorrect.
