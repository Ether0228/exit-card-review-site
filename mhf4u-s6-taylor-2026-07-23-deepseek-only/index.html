Q1. Which of the following reciprocal quadratic functions has no vertical asymptotes?

Official: C2 | Node: MHF4U-C-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student assumes every reciprocal quadratic has vertical asymptotes, ignoring the case where the denominator has no real zeros.

Remediation → err-type2-no-va-misconception | Retest → err-type2-no-va-misconception

  1. A. f(x)=2/(x^2-4)
    x^2-4 has zeros at x=2 and x=-2, so vertical asymptotes exist at those points.
  2. ✓ B. f(x)=2/(x^2+4)
    Correct. x^2+4 is always positive and has no real zeros, so no vertical asymptotes.
  3. C. f(x)=2/((x-1)(x+4))
    The denominator has zeros at x=1 and x=-4, so vertical asymptotes exist.
  4. D. f(x)=-1/(x^2+6x+8)
    x^2+6x+8 factors to (x+4)(x+2), so vertical asymptotes at x=-4 and x=-2.

Q2. For f(x)=(4x+10)/(3x-2), what is the horizontal asymptote?

Official: C2 | Node: MHF4U-C-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-2

Misconception: Student may swap a and c (giving y=3/4) or use the denominator constant (giving y=2/3).

Remediation → err-type3-parameter-mapping | Retest → err-type3-parameter-mapping

  1. ✓ A. y = 4/3
    Correct. a=4, c=3, so HA is y=4/3.
  2. B. y = 3/4
    That swaps the leading coefficients. The horizontal asymptote is y = a/c = 4/3, not 3/4.
  3. C. y = 2/3
    That uses the constant term of denominator. The HA uses the coefficients of x: numerator a over denominator c.
  4. D. y = -2/3
    The sign is incorrect; the HA is determined by a/c = 4/3.

Remediation → err-type3-parameter-mapping | Retest → err-type3-parameter-mapping

  1. ✓ A. f(x)=(-3x+6)/(-2x+4)

补救模块

err-type2-no-va-misconception

The student thinks that every reciprocal quadratic function must have vertical asymptotes, ignoring the possibility that the denominator quadratic may have no real roots (discriminant negative).

Explain: A reciprocal quadratic function f(x)=k/(ax²+bx+c) has vertical asymptotes only where the denominator equals zero. If the denominator quadratic has no real roots (discriminant < 0), then there are no vertical asymptotes. The graph is a smooth curve approaching y=0 on both sides.

Example: Consider f(x)=2/(x²+4). The denominator x²+4 is always positive (minimum 4), so it never equals zero. Thus, no vertical asymptotes. The y-intercept is 2/4=0.5, and the vertex of the reciprocal function is at (0, 1/2).

err-type3-parameter-mapping

Students often confuse the parameters a and c when finding the horizontal asymptote, or incorrectly apply the sign for the vertical asymptote. They may also forget to check if the function is truly rational (ad-bc ≠ 0) or a line with a hole.

Explain: For a Type 3 linear-over-linear rational function f(x) = (ax+b)/(cx+d), you can quickly find key features directly from the parameters: Horizontal asymptote (HA): y = a/c (the ratio of the leading coefficients). Vertical asymptote (VA): x = -d/c (set denominator to zero). X-intercept: set numerator=0 → x = -b/a. Y-intercept: set x=0 → y = b/d. IMPORTANT: The function is only a valid hyperbolic rational function if ad - bc ≠ 0. If ad - bc = 0, the function simplifies to a constant with a hole (not a true rational function with two asymptotes).

Example: Example: f(x) = (4x+10)/(3x-2). Here a=4, b=10, c=3, d=-2. HA: y = 4/3. VA: x = -(-2)/3 = 2/3. X-intercept: x = -10/4 = -2.5. Y-intercept: y = 10/(-2) = -5. Check validity: ad-bc = 4*(-2) - 10*3 = -8 - 30 = -38 ≠ 0, so it's a valid hyperbolic function. Invalid example: f(x) = (-3x+6)/(-2x+4). a=-3, b=6, c=-2, d=4. ad-bc = (-3)*4 - 6*(-2) = -12 + 12 = 0, so this simplifies to y=1.5 with a hole at x=2.

err-extraneous-solution-neglect

Students may think that algebraic manipulation always yields valid solutions, forgetting that rational equations have domain restrictions.

Explain: After solving a rational equation, you must check each candidate by substituting back into the original equation. If any denominator becomes zero, that candidate is extraneous and must be discarded.

Example: Solve x/(x-2) + 1/(x-4) = 2/(x²-6x+8). Factor denominator: (x-2)(x-4). Multiply by LCD: x(x-4) + (x-2) = 2 → x²-4x+x-2=2 → x²-3x-4=0 → (x-4)(x+1)=0 → x=4 or x=-1. Check x=4: denominators x-4=0, x²-6x+8=0 → undefined. So x=4 is extraneous. x=-1: denominators nonzero → valid.
