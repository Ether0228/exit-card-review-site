Q1. If a polynomial has a factor (x - 3)^2, what does the graph do at x = 3?

errorId: err-poly-factored-form | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Students may think order 2 means crossing or S-shaped crossing.

Remediation → err-poly-factored-form | Retest → err-poly-factored-form

  1. A. The graph crosses the x-axis with a linear shape.
    Order 2 does not produce a linear crossing. It bounces or touches.
  2. ✓ B. The graph bounces off the x-axis and turns around.
    Correct! Order 2 creates a parabolic bounce at the zero.
  3. C. The graph has an S-shaped cubic crossing.
    S-shaped crossing occurs for order 3, not order 2.
  4. D. There is no x-intercept at x = 3.
    If (x - 3) is a factor, there is an intercept at x = 3. Order 2 still has an intercept.

      补救模块

      err-poly-factored-form

      Students often think that any factor with an exponent greater than 1 still produces a simple crossing, or they confuse order 2 (bounce) with order 3 (S-shaped crossing).

      Explain: A polynomial in factored form is written as a product of linear factors (x - r)^order. The order (exponent) determines how the graph behaves at that x-intercept: order 1 = crosses linearly, order 2 = bounces off (parabolic touch), order 3 = crosses with an S-shaped cubic inflection. This is a key feature for sketching graphs.

      Example: For f(x) = (x - 2)^2 (x + 1), at x = 2 (order 2) the graph bounces, at x = -1 (order 1) it crosses linearly.

      err-poly-graphing-workflow

      Student may not follow the correct order of steps or may misinterpret end behavior rules.

      Explain: The graphing workflow for polynomials from factored form consists of four steps: 1) Find x-intercepts from factors. 2) Note the order of each factor to determine behavior at each intercept (order 1: linear crossing, order 2: parabolic bounce, order 3: S-shaped cubic crossing). 3) Determine end behavior using the degree (even/odd) and the sign of the leading coefficient (positive: right end up, negative: right end down). 4) Plot the intercepts, use the known shape at each, and connect from left to right, using a known point to scale if needed.

      Example: For a degree 4 polynomial with zeros at 2,6,10,14 all order 1 and passing through (3.5,0.5), we find end behavior: even degree, negative leading coefficient (since f(3.5)=0.5>0 and to the right of last zero, the graph goes down, so leading coeff negative). The graph crosses linearly at each zero. Using the point, we solve for leading coefficient a ≈ -0.002.
