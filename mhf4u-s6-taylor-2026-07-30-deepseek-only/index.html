Q3. Rewrite log₃ 5 using change of base formula with base 10.

Remediation → err-change-of-base-denominator | Retest → err-change-of-base-denominator

  1. A. (log₁₀ 3)/(log₁₀ 5)
    The formula is log_b A = (log_x A)/(log_x b). So log₃ 5 = (log₁₀ 5)/(log₁₀ 3).

  4. D. log₁₀ (5/3)
    That simplifies log of a quotient, not change of base.

补救模块

err-log-base-confusion

Student thinks that log (without a base) means natural logarithm (base e), but in mathematics and on calculators, unlabeled log indicates base 10.

Explain: A logarithm written as 'log' without a base is called the common logarithm and has base 10. The natural logarithm, written 'ln', has base e (approximately 2.718). These are different functions. For example, log 10 = 1 because 10^1 = 10, while ln 10 is about 2.302 (not 1). Always check the notation: log means base 10, ln means base e.

Example: Evaluate log 100: Since 10^2 = 100, log 100 = 2. If you mistakenly used ln, you would get ln 100 ≈ 4.605, which is incorrect.

err-argument-nonpositive

The student believes that logarithms can accept zero or negative arguments, ignoring the domain restriction that the argument must be strictly positive.

Explain: For log_b(x) to be defined as a real number, the argument x must be greater than 0. This is because b^y = x, and if b > 0 and b ≠ 1, then b^y is always positive for any real y. Therefore, there is no real exponent that gives a non-positive output.

Example: Consider log₁₀(-2). There is no real number y such that 10^y = -2, because 10 raised to any real power is positive. Similarly, log₁₀(0) is undefined because there is no y with 10^y = 0. So the domain of f(x)=log₁₀(x-4) is x > 4.

err-transformation-order

Student incorrectly believes that horizontal and vertical translations should be applied before stretch/reflection parameters.

Explain: For logarithmic functions in the form f(x)=A log₁₀[k(x-d)]+c, the correct order of transformations is: first apply the stretch/reflection parameters (A and k), then apply the translation parameters (d and c). This is because the transformations are applied to the basic function in the order they are performed - scaling/reflecting first, then shifting.

Example: For f(x) = -2 log₁₀ (x - 4), first reflect the base log graph in the x-axis and vertically stretch by factor 2. Then shift the graph 4 units to the right. Applying translation first would incorrectly shift the asymptote before stretching, leading to an incorrect graph.

err-asymptote-range

The student believes that parameters A (vertical stretch) or c (vertical translation) affect the vertical asymptote or restrict the range of a logarithmic function.

Explain: For any transformed logarithmic function f(x) = A log₁₀ [k(x - d)] + c, the vertical asymptote is determined solely by the horizontal shift d. It occurs when the argument k(x - d) = 0, which gives x = d. Stretches (A,k) and vertical shifts (c) do not move the asymptote. The range of every logarithmic function is all real numbers, regardless of transformations.

Example: Consider f(x) = -2 log₁₀ (x - 4). The vertical asymptote is at x = 4 (from d = 4). The range is y ∈ ℝ. Neither the vertical stretch by 2, the reflection in the x-axis, nor any translation changes the fact that the output can be any real number.

err-change-of-base-denominator

Student thinks change of base is log_b A = (log_x b)/(log_x A) or mixes up which log goes on top.

Explain: The change of base formula is log_b A = (log_x A)/(log_x b). The argument's log (A) goes in numerator, the base's log (b) goes in denominator.

Example: To rewrite log_4 32 using base 10: log_4 32 = (log_10 32)/(log_10 4).
