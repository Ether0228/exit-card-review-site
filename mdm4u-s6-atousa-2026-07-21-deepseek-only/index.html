Q1. When rolling a fair six-sided die, the expected value of the outcome is 3.5. Which of the following statements is true?

errorId: err-expected-value-possible-outcome | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Demonstrate an understanding of discrete probability distributions, represent th

Official: B1 | Node: MDM4U-B-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-2

Misconception: Student thinks expected value must be a possible outcome value.

Remediation → err-expected-value-possible-outcome | Retest → err-expected-value-possible-outcome

  1. A. 3.5 is the most likely outcome.
    3.5 is not a possible outcome, so it cannot be the most likely. The expected value is an average, not a specific outcome.
  2. B. 3.5 is impossible because the die only shows whole numbers.
    That is true, but it is still the expected value. The expected value does not have to be a possible outcome.
  3. ✓ C. 3.5 represents the average result over many rolls.
    Correct. The expected value is the long-run average.
  4. D. The expected value must be a whole number for a die.
    No, expected value can be any number. For a fair die, it is 3.5.

Q2. A student proposes the following probability distribution for the number of heads when tossing two coins: P(0)=0.25, P(1)=0.50, P(2)=0.30. Which condition for a valid probability distribution is violated?

Achievement: Knowledge and Understanding | Action: analyze | OSSD: Demonstrate an understanding of discrete probability distributions, represent th

Official: B1 | Node: MDM4U-B-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-2

Misconception: Student may think any set of numbers between 0 and 1 is valid even if not summing to 1.

Remediation → err-probability-sum-not-one | Retest → err-probability-sum-not-one

  1. A. Probabilities must be between 0 and 1.
    These probabilities are between 0 and 1, so that condition is satisfied.
  2. ✓ B. The sum of probabilities must equal 1.
    Correct. The sum is 0.25+0.50+0.30=1.05, which violates the condition.
  3. C. All outcomes must be equally likely.
    That is not a requirement for a valid probability distribution.
  4. D. Outcomes must be numeric.
    Outcomes can be categorical; numeric is not required.

    补救模块

    err-expected-value-possible-outcome

    Expected value is the long-term average, not necessarily a possible outcome. For example, rolling a fair die gives expected value 3.5, but no single roll shows 3.5.

    Explain: Expected value is the sum of each outcome multiplied by its probability. It represents the average result over many trials. It does not have to match any possible outcome. For instance, a fair six-sided die has outcomes 1,2,3,4,5,6 each with probability 1/6. E(X)= (1+2+3+4+5+6)/6 = 3.5. No single roll gives 3.5, but over many rolls the average will be close to 3.5.

    Example: Consider a spinner with 8 equal sections numbered 1 to 8. Each outcome has probability 1/8. The expected value is (1+2+...+8)/8 = 36/8 = 4.5. Spinning only yields whole numbers, but 4.5 is the long-run average.

    err-probability-sum-not-one

    Misunderstanding that the sum of probabilities in a valid distribution must equal exactly 1.

    Explain: A valid probability distribution must have two properties: (1) each probability is between 0 and 1 inclusive, and (2) the sum of all probabilities equals exactly 1. This represents that one of the outcomes must occur with 100% certainty across all possibilities.

    Example: For a fair coin, P(Heads)=0.5, P(Tails)=0.5, and 0.5+0.5=1. If someone incorrectly said P(Heads)=0.5, P(Tails)=0.4, the sum would be 0.9, which violates the rule because the outcomes don't cover all possibilities.

    err-net-expected-gain-no-cost

    The student believes that the expected value of the prize money is the net gain, ignoring the cost incurred to participate (e.g., ticket price, entry fee).

    Explain: Net expected gain is the long-term average profit per play. It is calculated as: Net Gain = Expected Winnings – Cost of Playing. The cost is a fixed amount you pay each time, so it must be subtracted. For example, if a lottery has expected winnings of $0.51 and a ticket costs $2, the net gain is $0.51 – $2 = -$1.48, meaning you lose $1.48 on average per ticket.

    Example: Church lottery: 2 million tickets at $2 each, prizes: one $1M, two $25k, five $1k. The expected winnings are $0.51 (from sum of (prize × probability)). The cost is $2. So expected net gain = $0.51 – $2 = -$1.48.

    err-dice-game-sign-confusion

    The student misunderstands that a negative expected value means the game is unfavorable for the player; they may think it still indicates possible profit or that the game is fair.

    Explain: The sign of the expected value tells you whether a game is favorable (positive) or unfavorable (negative) for the player over many plays. A negative expected value means the player loses money on average. For example, in a dice game where even rolls gain twice the face value and odd rolls lose triple the face value, the expected value is -0.5, meaning the player loses 50 cents per game on average.

    Example: In the dice game, outcomes: roll 1 (odd): lose 3, roll 2 (even): gain 4, roll 3 (odd): lose 9, roll 4 (even): gain 8, roll 5 (odd): lose 15, roll 6 (even): gain 12. Each probability 1/6. Expected value = (1/6)[(-3)+4+(-9)+8+(-15)+12] = (1/6)(-3) = -0.5. This negative result means the player will lose money over time.
