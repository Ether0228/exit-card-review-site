诊断卡

Q1. A bar graph showing company profits over 5 years uses a y-axis that starts at $10 million instead of $0. Which of the following is the most accurate statement about how this graph can mislead?

errorId: err-graphs-truncated-axis-only | Bloom: understand | Scaffold: L1

Achievement: Thinking | Action: interpret | OSSD: Analyse, interpret, and draw conclusions from one-variable data using numerical

Official: D1 | Node: MDM4U-D-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Thinking that a truncated y-axis is the only possible misleading feature, or that other elements like labels or titles can fix it.

Remediation → err-graphs-truncated-axis-only | Retest → err-graphs-truncated-axis-only

  1. ✓ A. It exaggerates differences because the axis is truncated.
    Correct. Starting the y-axis above zero makes small differences appear larger, exaggerating the visual impact.
  2. B. It is accurate because the axis labels are clear.
    Clear labels do not correct the distortion caused by a truncated axis. The visual impression is still misleading.
  3. C. It is misleading only if the sample size is small.
    Sample size is a separate issue. A graph can mislead through its axis scale regardless of sample size.
  4. D. It is not misleading because the graph includes a title.
    A title does not affect how the data is visually scaled. The truncated axis still distorts the message.

Q2. A line graph of temperature changes uses a y-axis from 20°C to 25°C to emphasize daily fluctuations. Which correction would make the graph less misleading?

errorId: err-graphs-correct-zoom-in | Bloom: apply | Scaffold: L2

Achievement: Application | Action: apply | OSSD: Analyse, interpret, and draw conclusions from one-variable data using numerical

Official: D1 | Node: MDM4U-D-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Thinking that zooming in or adding a trendline can fix a misleading axis scale.

Remediation → err-graphs-correct-zoom-in | Retest → err-graphs-correct-zoom-in

  1. A. Zoom in closer on the graph.
    Zooming in would further distort the scale, making fluctuations appear even larger.
  2. ✓ B. Reset the y-axis to start at 0°C.
    Correct. Resetting the axis to zero shows the true magnitude of the temperature changes and reduces exaggerated visual effects.
  3. C. Use a smaller sample size.
    A smaller sample size would likely introduce more uncertainty, not fix the axis distortion.
  4. D. Add a trendline.
    A trendline describes a relationship but does not address the misleading axis scale.

Q3. When performing manual linear regression, which set of sums is necessary and sufficient for computing the slope of the regression line?

errorId: err-regression-sum-confusion | Bloom: apply | Scaffold: L2

Achievement: Knowledge and Understanding | Action: apply | OSSD: Analyse, interpret, and draw conclusions from two-variable data using numerical,

Official: D2 | Node: MDM4U-D-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-2

Misconception: Confusing Σxy with Σx·Σy, or thinking Σy² is needed for slope.

Remediation → err-regression-sum-confusion | Retest → err-regression-sum-confusion

  1. A. Σx and Σy only
    These alone are insufficient; you also need Σxy and Σx² for the slope formula.
  2. B. Σxy and Σx² only
    Σx and Σy are also needed to complete the slope calculation (nΣxy - ΣxΣy) / (nΣx² - (Σx)²).
  3. ✓ C. Σx, Σy, Σxy, Σx²
    Correct. These four sums are the minimum required to compute the slope.
  4. D. Σx, Σy, Σxy, Σy²
    Σy² is needed for the correlation coefficient, not the slope. You need Σx², not Σy².

Q4. For a data point with an observed y-value of 15 and a model-predicted y-value of 12, what is the residual?

Official: D2 | Node: MDM4U-D-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-3

Misconception: Computing residual as predicted minus observed instead of the correct order.

Remediation → err-residual-sign | Retest → err-residual-sign

  1. A. -3
    This is predicted minus observed (12 - 15). Residuals are observed minus predicted.
  2. ✓ B. 3
    Correct. Residual = observed - predicted = 15 - 12 = 3.
  3. C. 27
    This is the sum, not the difference.
  4. D. -27
    This is the negative sum, not the residual.

Q5. A student wants to add a linear trendline and display the regression equation in Microsoft Excel. What is the critical first step before adding the trendline?

errorId: err-excel-trendline-chart-type | Bloom: analyze | Scaffold: L3

Achievement: Application | Action: analyze | OSSD: Analyse, interpret, and draw conclusions from two-variable data using numerical,

Official: D2 | Node: MDM4U-D-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-3

Misconception: Using a line chart instead of a scatter plot, which prevents correct regression equation generation.

Remediation → err-excel-trendline-chart-type | Retest → err-excel-trendline-chart-type

  1. A. Create a line chart of the data.
    A line chart treats x-values as categories, not numeric values, so it does not produce a correct regression trendline.
  2. ✓ B. Create a scatter plot (X,Y) of the data.
    Correct. A scatter plot treats both x and y as numeric, allowing Excel to compute a proper linear trendline and equation.
  3. C. Compute Σx and Σy manually.
    This is not necessary; Excel can generate the trendline directly from the scatter plot data.
  4. D. Insert a pivot table.
    A pivot table is used for data summarization, not for creating a trendline.

补救模块

err-graphs-truncated-axis-only

The student believes that a graph is not misleading once the axes are labelled or a title is added, or that the only visual distortion to watch for is a truncated y-axis. In reality, misleading graphs often combine multiple features such as starting the axis above zero, using overly small scale increments, leaving axes unlabeled, relying on small sample sizes, or using suggestive captions.

Explain: Misleading graphs often use a truncated y-axis starting above zero, overly small scale increments, unlabeled axes, small sample sizes, or suggestive captions. A graph can still be misleading even if the axes have clear labels and a title. To correct a misleading graph, reset the y-axis to zero, use evenly spaced scale increments, and show the true magnitude of the data fluctuations.

Example: A misleading stock price line graph uses a truncated y-axis to exaggerate price fluctuations. Simply relabelling the axis would not fix it; the y-axis must start at zero and use even spacing so the true size of the fluctuations is visible.

err-graphs-correct-zoom-in

The student believes that magnifying a graph reveals the true pattern, not realizing that a truncated y-axis or uneven scale still distorts the visual impression even when zoomed in.

Explain: Misleading graphs often use a truncated y-axis starting above zero, overly small scale increments, unlabeled axes, small sample sizes, or suggestive captions. To correct a misleading graph, reset the y-axis to zero, use evenly spaced scale increments, and show the true magnitude of data fluctuations. Zooming in does not fix the distortion; it can exaggerate it further.

Example: In the lesson, a misleading stock price line graph used a truncated y-axis that exaggerated price fluctuations. Correcting the graph meant resetting the y-axis to zero so the fluctuations appear in their true proportion. Similarly, a bar graph with small scale increments made small differences look large; the fix was to use even increments and a zero baseline.

err-regression-sum-confusion

The student believes the slope can be found with just the totals Σx and Σy, or that the product of the sums (Σx·Σy) is the same as the sum of the products (Σxy). This leads to incorrect substitution into the slope formula.

Explain: Manual linear regression requires computing five sums: Σx, Σy, Σxy, Σx², and Σy². The slope of the regression line uses only Σx, Σy, Σxy, and Σx²; Σy² is needed later for the correlation coefficient. The critical distinction is that Σxy means you first multiply each paired x and y value, then add those products. Σx·Σy means you add all x's, add all y's, then multiply the two totals—these are not interchangeable. Using the wrong one changes both the slope and the resulting regression equation.

Example: Take two data points (x₁, y₁) and (x₂, y₂). Σxy = x₁y₁ + x₂y₂, while Σx·Σy = (x₁+x₂)(y₁+y₂). Most of the time these are different, so substituting one for the other gives an incorrect slope. In Excel, the trendline does this automatically, but when calculating manually you must be careful to list each product before adding.

err-residual-sign

Student reverses the order in the residual formula, confusing predicted and observed values, leading to incorrect signs.

Explain: A residual measures how far a model's prediction is from the actual observed data point. By definition, residual = observed value minus predicted value. If the model predicts higher than the actual, the residual is negative; if lower, the residual is positive. The sign tells you whether the model over- or under-predicts.

Example: For a data point with observed y = 15 and model-predicted y = 12, the residual is 15 - 12 = 3, not 12 - 15 = -3. A positive residual means the observed value is above the prediction.

err-excel-trendline-chart-type

The student thinks a line chart and a scatter plot are interchangeable for adding a trendline. They do not realize that a line chart treats x-values as categories, not numbers, so Excel cannot generate a correct regression equation.

Explain: In Excel, a linear regression trendline gives the correct equation only when it is added to a scatter plot (X,Y). In a scatter plot, both axes are numeric and Excel uses the true x-values to compute the regression line. In a line chart, the x-axis is treated as a set of equally spaced categories, so the trendline is based on category positions rather than the actual numbers. This leads to an incorrect equation and can cause mismatches with manual calculations. The correct workflow is: insert a scatter plot, right-click a data point, choose 'Add Trendline', then select 'Linear'. The equation and coefficients are generated automatically.

Example: In the lesson, the instructor added a trendline to a scatter plot and produced the regression equation automatically. Students who used a line chart found that their trendline did not match the manual regression results because the line chart's x-axis was categorical. Switching to a scatter plot corrected the issue and produced the same equation as manual calculation.
