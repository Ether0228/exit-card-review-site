Q1. Which of the following correctly simplifies $\log_2(8+4)$?

errorId: err-log-laws-sum | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: LG1

Misconception: Assuming $\log(a+b) = \log a + \log b$.

Remediation → err-log-laws-sum | Retest → err-log-laws-sum

  1. A. $\log_2 8 + \log_2 4$
    The product rule applies to multiplication, not addition. $\log_2(8+4) = \log_2 12$, not a sum of logs.
  2. ✓ B. $\log_2 12$
    Correct. $8+4=12$, so the expression simplifies to $\log_2 12$.
  3. C. $\log_2 8 \times \log_2 4$
    This is not a valid logarithmic simplification; the log of a sum is not the product of the logs.
  4. D. $\log_2 (8\times4)$
    $8+4$ is not $8\times4$. The argument inside the log must remain as the sum.

Q2. What must be true for $\log_3(2x-5)$ to represent a real number?

errorId: err-log-domain | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: LG1

Misconception: Forgetting to check that arguments must be positive or solving the inequality incorrectly.

Remediation → err-log-domain | Retest → err-log-domain

  1. ✓ A. $x > \frac{5}{2}$
    Correct. For the log to be defined, $2x-5 > 0 \Rightarrow x > 5/2$.
  2. B. $x < \frac{5}{2}$
    If $x < 5/2$, then $2x-5$ becomes negative or zero, which is not allowed.
  3. C. $x > 0$
    While the whole argument must be positive, the restriction is $2x-5 > 0$, not just $x > 0$.
  4. D. $x > 5$
    Test $x=3$: $2(3)-5=1>0$, so $x > 5$ is too strict.

Q3. When solving $\log_2(x-3) + \log_2(x) = 2$, a student finds $x = -1$ and $x = 4$. Which statement is correct?

errorId: err-extraneous-check | Bloom: analyze | Scaffold: L2

Achievement: Thinking | Action: analyze | OSSD: Solve exponential and simple logarithmic equations in one variable algebraically

Official: A3 | Node: MHF4U-A-OE03 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: LG2

Misconception: Assuming all algebraic solutions are valid without checking if they make log arguments positive.

Remediation → err-extraneous-check | Retest → err-extraneous-check

  1. A. Both solutions are valid.
    $x = -1$ makes $\log_2(x-3) = \log_2(-4)$, which is undefined.
  2. B. $x = -1$ is valid because it satisfies the original equation.
    Even if it satisfies the transformed equation, a valid solution must keep all log arguments positive.
  3. ✓ C. $x = 4$ is valid because it makes both arguments positive.
    Correct. $x=4$ gives $\log_2(1) + \log_2(4) = 0+2=2$, and both arguments are positive.
  4. D. Neither solution is valid.
    $x = 4$ works as shown above; only $x = -1$ is extraneous.

Q4. Which expression correctly calculates $\log_5 20$ using common logarithms (base 10)?

errorId: err-change-base | Bloom: apply | Scaffold: L2

Achievement: Knowledge and Understanding | Action: apply | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: LG3

Misconception: Writing $\frac{\log_c b}{\log_c x}$ instead of $\frac{\log_c x}{\log_c b}$.

Remediation → err-change-base | Retest → err-change-base

  1. ✓ A. $\frac{\log 20}{\log 5}$
    Correct. Change of base: $\log_5 20 = \frac{\log_{10} 20}{\log_{10} 5}$.
  2. B. $\frac{\log 5}{\log 20}$
    This is the reciprocal; it would compute $\log_{20} 5$.
  3. C. $\log 20 - \log 5$
    That would be $\log(20/5) = \log 4$, not $\log_5 20$.
  4. D. $\log 20 + \log 5$
    That would be $\log(20\times5) = \log 100 = 2$, not related.

Q5. Simplify $(2^3)^2$.

errorId: err-exponent-confusion | Bloom: apply | Scaffold: L1

Achievement: Knowledge and Understanding | Action: apply | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: LG1

Misconception: Adding the exponents: $(a^m)^n = a^{m+n}$.

Remediation → err-exponent-confusion | Retest → err-exponent-confusion

  1. A. $2^5$
    That would be $2^3 \cdot 2^2$, not a power of a power.
  2. ✓ B. $2^6$
    Correct. $(2^3)^2 = 2^{3\times2} = 2^6$.
  3. C. $2^8$
    That would be $2^4 \cdot 2^4$, not the given expression.
  4. D. $2^1$
    That would be $\frac{2^3}{2^2}$, not a power of a power.

补救模块

err-log-laws-sum

The student incorrectly applies the product rule of logarithms to a sum, believing log(a+b) = log a + log b.

Explain: The product rule for logarithms says that when adding two logs with the same base, you multiply their arguments: log_a(xy) = log_a x + log_a y. It does NOT say that the log of a sum equals the sum of the logs. In other words, log_a(x+y) is not log_a x + log_a y. The only operation that creates a sum of logs is multiplication inside a single log.

Example: From the lesson: log₃ 6 + log₃ 4.5 = log₃(6 × 4.5) = log₃ 27 = 3. Here the plus sign is between two logs, so we combine the arguments by multiplying. If the expression were log₃(6 + 4.5), it would be log₃ 10.5, which is not 3.

err-log-domain

The student forgets that logarithm arguments must be strictly positive. They may accept negative or zero inputs as valid, causing them to miss domain restrictions or keep invalid solutions.

Explain: A logarithm log_a x is only defined for x > 0 (with a > 0, a ≠ 1). Whenever a logarithm appears, its argument must be strictly greater than zero. When solving logarithmic equations, all algebraic solutions must be checked in the original equation to ensure every logarithm has a positive argument. Any solution that creates a zero or negative argument is rejected.

Example: For log_3(2x-5), the argument must be positive: 2x - 5 > 0. Solving gives x > 5/2. This means x = 2 is not allowed because 2(2)-5 = -1, but x = 3 is allowed because 2(3)-5 = 1 > 0.

err-extraneous-check

Students often forget that logarithm arguments must be positive. After solving a logarithmic equation, they must substitute solutions back to ensure no argument is ≤0; otherwise, those solutions are extraneous and must be discarded.

Explain: When solving logarithmic equations, always check your solutions. Any solution that makes the argument of any logarithm zero or negative is invalid (extraneous). This is because the domain of log_a(x) is x>0.

Example: Solve log_2(x-3) + log_2(x) = 2. Step 1: Combine logs: log_2(x(x-3)) = 2 → x^2 - 3x = 4 → x^2 - 3x - 4 = 0 → (x-4)(x+1)=0 → x=4, x=-1. Step 2: Check: For x=4, logs are log_2(1) and log_2(4), both valid. For x=-1, log_2(-4) is undefined. So only x=4 is valid.

err-change-base

The student inverts the change of base formula, writing log_c b / log_c x instead of log_c x / log_c b. They likely confuse which value (the original base versus the argument) should be the numerator and which should be the denominator when converting to a new base.

Explain: The change of base formula states: log_b x = log_c x / log_c b. It allows you to rewrite a logarithm with any new base c. The argument x is the numerator, and the original base b is the denominator. This is not simply flipping the fraction. To see why, let y = log_b x, so b^y = x. Taking log_c of both sides gives y log_c b = log_c x, so y = log_c x / log_c b. The argument x is divided by the base b, not the other way around.

Example: To evaluate log_2 48 using common logs, write: log_2 48 = log_10 48 / log_10 2. The argument 48 goes on top, the original base 2 goes on bottom. Similarly, log_3 6 = log_10 6 / log_10 3.

err-exponent-confusion

The student confuses the power of a power rule ((a^m)^n = a^(m*n)) with the product rule (a^m * a^n = a^(m+n)), often adding exponents when they should multiply.

Explain: When you raise a power to another power, you multiply the exponents. For example, (2^3)^2 means you have (2^3) multiplied by itself: (2^3)*(2^3) = 2^(3+3) = 2^6, but a shortcut is to multiply the exponents: 3 * 2 = 6, so (2^3)^2 = 2^6. Do not add them; adding is for multiplying powers with the same base: 2^3 * 2^2 = 2^(3+2) = 2^5.

Example: Simplify (2^3)^2: Multiply 3 and 2 to get 6, so it equals 2^6 = 64. Contrast with 2^3 * 2^2 = 2^(3+2) = 2^5 = 32. Notice the parentheses: they indicate power of a power.
