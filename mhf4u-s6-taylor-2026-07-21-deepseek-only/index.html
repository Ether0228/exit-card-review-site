    补救模块

    err-poly-eq-root-screening

    The student assumes that all algebraic solutions of the polynomial equation are valid, without verifying whether they satisfy the context or domain restrictions. This often leads to including extraneous roots.

    Explain: When solving polynomial equations in a real-world context, you must check that each candidate root falls within the specified domain (e.g., time interval, length, etc.). Only roots within the domain are meaningful. For example, in the Orca motion problem, the depth functions were set equal, yielding t=1.5, t=4, and t=9. Since the observation window is 0 to 8 seconds, only t=1.5 and t=4 are valid; t=9 is discarded.

    Example: Orca problem: solve h1(t)=h2(t) → (t-4)(t-9) factor gives roots 4 and 9; but domain is [0,8], so discard 9. Also synthetic division gave t=1.5 as a root, which is within domain.

    err-poly-eq-synthetic-division

    The student may be confusing the divisor sign, misordering coefficients, or not carrying down correctly when performing synthetic division.

    Explain: Synthetic division is a shortcut for dividing a polynomial by (x - c). Steps: (1) Write the root c (the value that makes the divisor zero). (2) Write the coefficients of the polynomial in descending order of degree, including zeros for missing terms. (3) Bring down the first coefficient. (4) Multiply that coefficient by c, add the result to the next coefficient, and write the sum below. (5) Repeat: multiply this sum by c, add to the next coefficient, and so on. (6) The last number is the remainder; the other numbers are coefficients of the quotient (one degree less than the original).

    Example: Divide x³ - 2x² + 3x - 2 by (x - 1). Root = 1. Coefficients: 1, -2, 3, -2. Bring down 1. Multiply 1×1 = 1, add to -2 → -1. Multiply 1×(-1) = -1, add to 3 → 2. Multiply 1×2 = 2, add to -2 → 0. Quotient: x² - x + 2, remainder 0.

    err-poly-eq-factoring

    Student believes that once synthetic division is performed, the polynomial is fully factored, overlooking that the quotient polynomial may still be factorable.

    Explain: When solving polynomial equations, after using synthetic division to factor out one root, you obtain a reduced polynomial (often quadratic). You must check if this reduced polynomial can be factored further. For example, if synthetic division yields (x-2)(x² - 4x + 3), the quadratic x² - 4x + 3 can be factored as (x-1)(x-3) to give the complete factorization (x-1)(x-2)(x-3).

    Example: Solve x³ - 6x² + 11x - 6 = 0. Using synthetic division with root 2 gives (x-2)(x² - 4x + 3). Now factor x² - 4x + 3: find two numbers that multiply to 3 and add to -4: -1 and -3. So it factors as (x-1)(x-3). Thus the polynomial fully factors as (x-1)(x-2)(x-3), and the solutions are x=1,2,3.

    err-poly-ineq-flip-sign

    Student treats inequality as an equation and does not flip the sign when multiplying or dividing by a negative.

    Explain: When multiplying or dividing both sides of an inequality by a negative number, the inequality sign must be flipped. This is because multiplying by a negative reverses the order on the number line. For example, -3x > 6 becomes x < -2 after dividing by -3 and flipping the sign.

    Example: Solve -2x > 4: Divide both sides by -2 and flip the '>' to '<': x < -2

    err-poly-ineq-quadratic-pattern

    Students think x² > a means x > √a only, forgetting the negative branch x < -√a. Similarly, for x² < a, they may write x < √a instead of the double inequality -√a < x < √a.

    Explain: For quadratic inequalities, the solution set depends on the direction of the inequality and the sign of a. For x² > a where a > 0, the graph of y = x² is above the horizontal line y = a for x < -√a and x > √a, so the solution is x < -√a or x > √a. For x² < a, the graph is below the line, so -√a < x < √a. If a < 0, then x² > a is always true (since x² ≥ 0 > a) and x² < a has no solution. Always consider both positive and negative roots.

    Example: Solve x² > 4. Take square root: √4 = 2. Since inequality is >, solution is x < -2 or x > 2. Solve x² < 4: solution is -2 < x < 2.

    err-poly-ineq-interval-testing

    Students think testing one interval is enough or forget that each interval must be tested separately.

    Explain: When solving a polynomial inequality, after factoring and finding zeros, plot them on a number line. This splits the number line into intervals. You must test a sample point from each interval to determine the sign of the expression in that interval.

    Example: For zeros at -2, 1, 3, 5, the intervals are: (-∞, -2), (-2, 1), (1, 3), (3, 5), (5, ∞). Choose test points like -3, 0, 2, 4, 6 and evaluate the inequality to see which intervals satisfy it.

    err-poly-nonfactorable-misconception

    Student believes that all polynomials must cross the x-axis, or that non-factorable polynomials have no real roots.

    Explain: Odd-degree polynomials always have at least one real root because their ends go in opposite directions, forcing a crossing of the x-axis. Even-degree polynomials, if non-factorable, may lie entirely above the x-axis (positive leading coefficient) or entirely below (negative leading coefficient), meaning they have no real roots.

    Example: Consider x³ - 2x + 3. This odd-degree polynomial is non-factorable but must have at least one real root. In contrast, x² + 1 is even-degree and non-factorable; it never crosses the x-axis because it lies entirely above.
