Q1. In a grid where only diagonal moves are allowed, the number of paths to a node equals the sum of paths to all reachable preceding nodes. If node X can be reached from node Y with 4 paths and from node Z with 6 paths, how many paths lead to node X?

Remediation → err-mdm4u-path-counting | Retest → err-mdm4u-path-counting

  1. ✓ A. 10
    Correct! The paths add: 4 + 6 = 10.
  2. B. 24
    You multiplied instead of adding. The total paths is the sum of paths from all preceding nodes.
  3. C. 4
    You only considered one path to node X. You must include both Y and Z paths.
  4. D. 6
    You only considered one path to node X. You must include both Y and Z paths.

补救模块

err-mdm4u-path-counting

Confuses addition with multiplication in path counting; thinks path counts combine multiplicatively rather than additively.

Explain: In path counting with valid moves (e.g., diagonals), the number of ways to reach a node is the sum of the ways to reach each node that leads directly to it. This is the additive principle. You add counts, never multiply them from different incoming paths.

Example: If node X is reachable from node Y (4 ways) and from node Z (6 ways), then total paths to X = 4 + 6 = 10.
