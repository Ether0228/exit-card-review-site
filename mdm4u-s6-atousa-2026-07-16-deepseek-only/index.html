诊断卡

Q1. A school club has 12 members. They need to select a president, vice-president, and treasurer (each a different person). Which counting method should be used to find the number of ways to fill these three positions?

errorId: err-comb-vs-perm | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: apply | OSSD: Solve problems involving the application of permutations and combinations to det

Official: A2 | Node: MDM4U-A-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student may think selection of three people from 12 is a combination, forgetting that positions make the order significant.

Remediation → err-comb-vs-perm | Retest → err-comb-vs-perm

  1. A. Combination C(12,3) because we are choosing 3 people.
    Selection without regard to order would be C(12,3), but here the roles (president, VP, treasurer) are different, so order matters.
  2. ✓ B. Permutation P(12,3) because each position is distinct.
    Correct. Since the positions are different, the arrangement matters, so we use P(12,3).
  3. C. Permutation P(12,3) but order doesn't matter.
    Permutations always consider order. If order did not matter, we would use combination.
  4. D. Combination C(12,3) multiplied by 3! because positions can be swapped.
    This is a common trick: C(12,3)*3! = P(12,3). But the direct method is P(12,3); using combination and then multiplying by 3! is an equivalent approach but not the simplest identification.

Q2. Evaluate C(5,0). What is its value?

errorId: err-factorial-zero | Bloom: remember | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Solve problems involving the application of permutations and combinations to det

Official: A2 | Node: MDM4U-A-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student may think C(5,0)=0 or that it is undefined because selecting 0 items seems like nothing.

Remediation → err-factorial-zero | Retest → err-factorial-zero

  1. A. 0
    C(5,0) counts the number of ways to choose 0 items from 5. There is exactly one way: choose nothing. So it is 1, not 0.
  2. ✓ B. 1
    Correct. C(5,0)=1 because there is exactly one way to select nothing.
  3. C. 5
    C(5,1)=5, but C(5,0) is not the same. Recall the formula: C(5,0)=5!/(0!5!) = 120/(1*120)=1.
  4. D. Undefined because you cannot choose 0 items
    Choosing 0 items is a valid selection; it corresponds to the empty set. Mathematically, it is defined and gives 1.

Q3. Two fair dice are rolled. Event A: first die shows a 6. Event B: second die shows a 5. What is the probability that both events occur?

errorId: err-multiply-when-add | Bloom: apply | Scaffold: L2

Achievement: Knowledge and Understanding | Action: apply | OSSD: Solve problems involving the probability of an event or a combination of events

Official: A1 | Node: MDM4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-2

Misconception: Student may add probabilities (1/6+1/6=2/6) because they confuse 'and' with 'or'.

Remediation → err-multiply-when-add | Retest → err-multiply-when-add

  1. A. 1/6 + 1/6 = 1/3
    You added the probabilities. For independent events, P(A and B) = P(A)*P(B), not P(A)+P(B).
  2. ✓ B. 1/6 * 1/6 = 1/36
    Correct. Since the dice rolls are independent, multiply the probabilities.
  3. C. 2/12 = 1/6
    This is not the correct computation. You might have added the numerators and denominators incorrectly.
  4. D. 1/6 (because one of the dice must show the required number)
    The probability of both events is less than the probability of either alone. Multiplication gives a smaller probability.

Q4. A family of 5 people (parents and 3 children) are to sit in a row of 5 chairs. What is the probability that the two parents sit next to each other?

errorId: err-adjacent-group | Bloom: analyze | Scaffold: L3

Achievement: Thinking | Action: analyze | OSSD: Solve problems involving the application of permutations and combinations to det

Official: A2 | Node: MDM4U-A-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-3

Misconception: Student may not treat the two parents as a block, or may forget to account for internal arrangements of the block (2!).

Remediation → err-adjacent-group | Retest → err-adjacent-group

  1. A. 4! / 5! = 1/5
    You forgot to account for the internal arrangement of the two parents within the block, which adds a factor of 2!.
  2. ✓ B. 4! * 2! / 5! = 2/5
    Correct. Treat the two parents as a single entity, giving 4! arrangements for the block and the others, multiplied by 2! for the parents' arrangement, divided by total arrangements 5!.
  3. C. 2! * 3! / 5! = 1/10
    This uses only the parents' arrangement and children's arrangement, but ignores the number of positions the block can occupy.
  4. D. 5! / (5! - 2!) = 1/2
    This is not a correct application of probability. Remember to count favorable arrangements using permutations with constraints.

Q5. A 4-digit PIN is formed using the digits 0-9 without repetition. What is the total number of possible PINs?

errorId: err-sample-space-miscount | Bloom: apply | Scaffold: L2

Achievement: Knowledge and Understanding | Action: apply | OSSD: Solve problems involving the application of permutations and combinations to det

Official: A2 | Node: MDM4U-A-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student might use combination (C(10,4)) because they forget order matters in a PIN, or use 10^4 (with repetition).

Remediation → err-sample-space-miscount | Retest → err-sample-space-miscount

  1. A. C(10,4) = 210
    Combination counts selections without regard to order, but PIN order matters. For example, 1234 and 4321 are different PINs.
  2. B. 10^4 = 10000
    10^4 would be correct if digits could repeat, but the problem says without repetition.
  3. ✓ C. P(10,4) = 5040
    Correct. Order matters and digits cannot repeat, so we use permutation: 10*9*8*7 = 5040.
  4. D. 10*9*8*7 = 5040, but since repetition is not allowed, you should divide by 4! to get C(10,4) = 210.
    This reasoning is incorrect. The correct count uses permutations because order matters: P(10,4) = 10*9*8*7 = 5040. Dividing by 4! would give combinations, which ignore order.

补救模块

err-comb-vs-perm

The student fails to recognize whether order is important in a counting problem. They may think that selecting items always means combination, or that ordering always applies.

Explain: When counting, decide if order matters. For ordered arrangements (like positions, codes, rankings), use permutations P(n,r) = n!/(n-r)!. For unordered selections (like committees, hands of cards), use combinations C(n,r) = n!/(r!(n-r)!).

Example: Selecting a committee of 5 from 14 people: order doesn't matter → C(14,5)=2002. Ranking the top 3 from 12 forwards: order matters → P(12,3)=1320.

err-factorial-zero

Student believes that 0! = 0, often because they think the factorial of zero is zero since there are no numbers to multiply, or they misinterpret the definition.

Explain: Factorial n! is defined as the product of all positive integers from 1 to n, and by convention 0! = 1. This is necessary for formulas like C(n,r) = n!/(r!(n-r)!) to work correctly for r=0 and r=n. For example, choosing 0 items from a set should have exactly 1 way (the empty selection), so C(n,0)=1 requires 0!=1.

Example: Evaluate C(5,0): Using the formula, C(5,0) = 5!/(0!5!) = 120/(1×120) = 1. This matches the intuitive idea that there is exactly one way to choose nothing.

err-multiply-when-add

You might confuse the rules for 'or' (addition for mutually exclusive events) with 'and' (multiplication for independent events). When both events must happen, their joint probability is the product of their individual probabilities if they do not affect each other.

Explain: When two events A and B are independent, the probability that both occur is P(A and B) = P(A) * P(B). Independence means the outcome of one event does not change the probability of the other. Addition, P(A) + P(B), is used only when events are mutually exclusive and we want the probability that either occurs.

Example: Suppose the probability of winning a prize in a single raffle draw is 2/9. If you enter two independent draws, the probability of winning both times is (2/9) * (2/9) = 4/81.

err-adjacent-group

When items must be together in an arrangement, students often count them as separate items without considering that they act as a single unit, or they forget that the items within the block can be rearranged among themselves.

Explain: To solve problems where certain items must be adjacent, treat the group as a single 'block'. Count the number of ways to arrange this block along with the other items, then multiply by the number of ways to arrange the items inside the block.

Example: In a photo line of 9 people, if Jill and David must sit together, treat them as one block. Then we have 8 entities (the block + 7 other people) which can be arranged in 8! ways. Inside the block, Jill and David can switch positions: 2! ways. So favorable arrangements = 8! × 2! = 40320 × 2 = 80640. Total arrangements without restrictions: 9! = 362880. Probability = (8! × 2!)/9! = 2/9.

err-sample-space-miscount

The student misunderstands whether the order of outcomes matters in the context of the problem. They may default to using permutations for all ordered scenarios or combinations for all unordered scenarios without considering the specific condition of the problem.

Explain: The sample space consists of all possible outcomes of an experiment. To count outcomes correctly, you must decide whether order matters. If order matters, use permutations P(n,r). If order does not matter, use combinations C(n,r). Always ask: 'Does rearranging the selected items create a different outcome?' If yes, order matters.

Example: Consider a combination lock with numbers 0-59 (60 numbers) and a 3-digit code without repeating digits. The code 12-5-7 is different from 5-12-7, so order matters. Total codes = P(60,3) = 60×59×58 = 205,320. Using combination would give C(60,3) = 34,220, which is incorrect because it treats different orders as the same code.
