Q1. Which logarithmic equation is equivalent to 2^3 = 8?

errorId: err-log-definition | Bloom: understand | Scaffold: L1

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Demonstrate an understanding of the relationship between exponential expressions

Official: A1 | Node: MHF4U-A-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student may confuse the roles of base, exponent, and result, e.g., writing log_8 2 = 3.

Remediation → err-log-definition | Retest → err-log-definition

  1. ✓ A. log₂ 8 = 3
    Correct! The base of the exponent (2) becomes the base of the logarithm, the result (8) is the argument, and the exponent (3) is the value.
  2. B. log₈ 2 = 3
    Almost, but check the order: the base of the exponential expression becomes the base of the logarithm, not the argument.
  3. C. log₃ 2 = 8
    The exponent (3) should become the value of the logarithm, not the base.
  4. D. log₂ 3 = 8
    The argument of the logarithm should be the result of the exponentiation (8), not the exponent (3).

    Q4. The graph of y = log₃ x is shown. What is the domain of this function?

    errorId: err-log-definition | Bloom: understand | Scaffold: L2

    Achievement: Knowledge and Understanding | Action: interpret | OSSD: Identify and describe some key features of the graphs of logarithmic functions,

    Official: A2 | Node: MHF4U-A-OE02 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

    Learning Goal: lg-3

    Misconception: Student may think domain is all real numbers (confusing with exponential domain) or x≥0.

    Remediation → err-log-definition | Retest → err-log-definition

    1. A. All real numbers
      For y = log₃ x, the argument x must be positive because you cannot take the logarithm of zero or a negative number.
    2. ✓ B. x > 0
      Correct! Since log₃ x is the inverse of 3^x, its domain is the range of exponential: x > 0.
    3. C. x ≥ 0
      The logarithm of 0 is undefined (3^y = 0 has no solution), so x cannot be 0.
    4. D. x ≠ 0
      While x=0 is problematic, negative numbers are also not allowed. The domain is x > 0.

    补救模块

    err-log-definition

    The student may confuse which part of the exponential expression becomes the base, argument, or result in the logarithmic form. They might think the exponent becomes the base or the result becomes the base.

    Explain: The logarithmic form is the inverse of the exponential form. For y = a^x, the inverse is x = a^y, which is written as y = log_a x. The base a stays the same, the result of the exponentiation becomes the argument of the logarithm, and the exponent becomes the output of the logarithm.

    Example: Convert 2^3 = 8 to logarithmic form: the base is 2, the result is 8, and the exponent is 3, so log_2 8 = 3.

    err-log-base-restriction

    Student believes any positive number can be a base for a logarithmic function, including 1.

    Explain: The base a of a logarithmic function y = log_a x must be greater than 0 and not equal to 1. If a = 1, then 1^y = 1 for all y, so the equation x = 1^y would only be satisfied if x = 1, making it impossible to define a unique logarithm for any other x. Similarly, if a ≤ 0, the exponential function is not well-defined for all real exponents. Therefore, the valid base set is (0,1) ∪ (1, ∞).

    Example: Consider a = 1: What is log_1 8? We need 1^? = 8. Since 1 raised to any power is 1, there is no solution, so log_1 8 is undefined. Hence a = 1 is not allowed.
