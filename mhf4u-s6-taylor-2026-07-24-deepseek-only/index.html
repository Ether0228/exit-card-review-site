补救模块

err-rational-eq-domain

The student fails to recognize that values causing any denominator to be zero are not allowed in the domain of a rational equation. They may solve algebraically correctly but forget to exclude extraneous roots that make the denominator zero.

Explain: When solving rational equations, always identify the values that make any denominator zero. These values are excluded from the domain. After solving, check that each solution is not equal to any excluded value. If it is, it is extraneous and must be discarded.

Example: Solve (5x+1)/(x-2)=0. Multiply both sides by (x-2): 5x+1=0 => x=-1/5. The denominator zero when x=2, so x=2 is excluded. Since -1/5 is not 2, the solution is valid. Solution set: {-1/5}.

err-rational-ineq-multiply

Students often treat rational inequalities like equations and multiply by the denominator without considering that the sign of the denominator can change the inequality direction.

Explain: When solving rational inequalities, you cannot multiply both sides by a denominator that contains a variable because its sign is unknown. Multiplying by a negative value reverses the inequality. The correct method is to bring all terms to one side, combine into a single fraction, and compare to zero.

Example: Solve (x+3)/(x-1) < 5. Wrong: Multiply by (x-1) to get x+3 < 5x-5 => 8 < 4x => x > 2, which misses the case when (x-1) is negative. Correct: Subtract 5: (x+3)/(x-1) - 5 < 0 => (x+3 -5(x-1))/(x-1) < 0 => (-4x+8)/(x-1) < 0 => -4(x-2)/(x-1) < 0. Divide by -4 (reverses inequality): (x-2)/(x-1) > 0. Critical points: x=1, x=2. Test intervals: (-∞,1): both negative => positive, true; (1,2): numerator negative, denominator positive => negative, false; (2,∞): both positive => positive, true. Solution: (-∞,1) ∪ (2,∞).

err-rational-ineq-endpoint

The student mistakenly includes or excludes endpoints when solving rational inequalities. They may include values that make denominator zero (always excluded) or exclude numerator zeros when the inequality is non-strict.

Explain: When solving rational inequalities, critical points come from numerator zeros (where expression equals zero) and denominator zeros (where expression is undefined). Denominator zeros are always excluded from solution sets because division by zero is undefined. Numerator zeros are included only if the inequality is non-strict (≤ or ≥); they are excluded for strict inequalities (< or >). Example: For ≤ or ≥, include numerator zeros; for < or >, exclude them.

Example: Solve (x²-5x-14)/(x²+2x-15) ≤ 0. Factor: numerator (x-7)(x+2), denominator (x+5)(x-3). Critical points: numerator zeros -2 and 7, denominator zeros -5 and 3. Because inequality is ≤, include -2 and 7 (numerator zeros) but exclude -5 and 3 (denominator zeros). Test intervals yield solution (-5,-2] ∪ (3,7].

err-rational-ineq-factor

The student fails to correctly factor the numerator and denominator of a rational expression, leading to missing or incorrect critical points for interval testing.

Explain: To solve a rational inequality, first rearrange it to the form P(x)/Q(x) [comparator] 0. Then factor both the numerator and denominator completely. The critical points are the values of x that make either factor zero. These points divide the number line into intervals for testing. Remember: values that make the denominator zero are always excluded from the solution, but they are still critical points for sign analysis.

Example: Solve (x²-5x-14)/(x²+2x-15) ≤ 0. First factor: numerator = (x-7)(x+2), denominator = (x+5)(x-3). Critical points: from numerator zeros: x=7, x=-2; from denominator zeros: x=-5, x=3. So critical points are -5, -2, 3, 7.
