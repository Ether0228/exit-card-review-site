Q1. Which statement about a fifth-degree polynomial function is correct?

errorId: err-polynomial-degree-function-parity | Bloom: understand | Scaffold: L2

Achievement: Knowledge and Understanding | Action: interpret | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-1

Misconception: Student thinks odd-degree polynomial must be an odd function or even-degree must be even function.

Remediation → err-polynomial-degree-function-parity | Retest → err-polynomial-degree-function-parity

  1. A. It must be an odd function because the degree is odd.
    An odd-degree polynomial does not have to be an odd function. Function parity depends on symmetry about the origin, not just the degree.
  2. ✓ B. It is not necessarily an odd function; degree parity and function parity are independent.
    Correct. A fifth-degree polynomial can be neither odd nor even; its parity depends on the specific coefficients.
  3. C. It must be an even function because all polynomials are symmetric.
    Polynomials are not necessarily symmetric. Even-degree polynomials have symmetry about the y-axis only if they are even functions, but that is not guaranteed.
  4. D. It cannot be an odd function because the degree is odd.
    It can be odd if it satisfies f(-x) = -f(x), for example f(x) = x^5. So degree parity alone does not determine function parity.

Q2. Which of the following is the correct formal description of the end behavior of an even-degree polynomial with a positive leading coefficient?

Learning Goal: lg-2

Misconception: Student uses quadrant references (e.g., 'from quadrant III to quadrant I') instead of describing direction.

Remediation → err-end-behavior-quadrant | Retest → err-end-behavior-quadrant

  1. ✓ A. Both ends go up.
    Correct. Even-degree with positive leading coefficient: as x → ±∞, y → +∞.

    That describes an odd-degree polynomial, not even-degree.
  3. C. It goes from Q2 to Q1.

  4. D. Both ends go down.
    That would be correct for a negative leading coefficient, not positive.

Q3. For a cubic polynomial (degree 3), the constant third difference (CD) is 12. Which formula correctly relates the constant difference to the leading coefficient a?

errorId: err-finite-difference-misapplication | Bloom: apply | Scaffold: L2

Achievement: Application | Action: apply | OSSD: Identify and describe some key features of polynomial functions, and make connec

Official: C1 | Node: MHF4U-C-OE01 | Source: https://www.edu.gov.on.ca/eng/curriculum/secondary/math1112currb.pdf

Learning Goal: lg-3

Misconception: Student uses CD = n * a instead of CD = n! * a.

Remediation → err-finite-difference-misapplication | Retest → err-finite-difference-misapplication

  1. A. CD = 3 × a, so a = 12 / 3 = 4
    The formula uses factorial, not just n. CD = 3! × a = 6a, so a = 12 / 6 = 2.
  2. ✓ B. CD = 3! × a, so a = 12 / 6 = 2
    Correct. CD = n! × a, so for n=3, CD = 6a, a = 2.
  3. C. CD = 3^2 × a, so a = 12 / 9 = 1.33
    The formula uses factorial, not square. CD = 3!×a = 6a.
  4. D. CD = a, so a = 12
    The constant difference is related to a by CD = n!×a. It is not equal to a.

补救模块

err-polynomial-degree-function-parity

Student confuses polynomial degree parity (even/odd degree) with the property of a function being odd or even. They may think that an odd-degree polynomial is necessarily an odd function or that an even-degree polynomial is necessarily an even function.

Explain: Polynomial degree parity (even or odd degree) is independent of whether the polynomial function is odd or even. An odd-degree polynomial does not have to be an odd function, and an even-degree polynomial does not have to be an even function. Function parity refers to symmetry: even functions satisfy f(-x)=f(x) and odd functions satisfy f(-x)=-f(x). Degree parity only tells us about end behavior: even-degree polynomials have both ends going the same direction, odd-degree have ends opposite. Do not assume a polynomial's function parity based solely on its degree.

Example: Consider the polynomial x^4 - 2x^3 + 5. Its degree is 4 (even), but it is not an even function because f(-x)=(-x)^4 - 2(-x)^3 + 5 = x^4 + 2x^3 + 5, which is not equal to f(x). Thus, an even-degree polynomial can be neither even nor odd.

err-end-behavior-quadrant

End behavior must be described using formal descriptive expressions (e.g., 'as x → ∞, y → ∞') rather than quadrant references (e.g., 'from Q3 to Q2').

Explain: End behavior describes what happens to y as x approaches positive or negative infinity. Instead of saying 'from quadrant II to quadrant I', we use formal language: 'as x → -∞, y → ... ; as x → ∞, y → ...'. For even-degree polynomials, both ends go in the same direction; for odd-degree, they go opposite directions.

Example: For a quadratic with positive leading coefficient, as x → ±∞, y → ∞ (both ends up). For a cubic with positive leading coefficient, as x → -∞, y → -∞ and as x → ∞, y → ∞ (one down, one up).

err-finite-difference-misapplication

Student thinks the constant difference for an nth-degree polynomial is n times the leading coefficient, rather than n factorial times the leading coefficient.

Explain: The finite difference rule states that an nth-degree polynomial has constant nth-order differences. The constant difference (CD) is given by CD = n! * a, where a is the leading coefficient. For example, for a cubic (n=3), CD = 3! * a = 6a. For a quartic (n=4), CD = 4! * a = 24a. Remember that n! (n factorial) is the product of all positive integers up to n, so 3! = 3×2×1 = 6, 4! = 4×3×2×1 = 24.

Example: Consider the cubic polynomial 2x^3 + ... Its constant third difference is CD = 3! * 2 = 12. For the quartic polynomial x^4 - 2x^3 + 5, the leading coefficient a=1, degree n=4, so CD = 4! * 1 = 24.

err-missing-term-coefficient

The student forgets that missing terms in a polynomial correspond to a coefficient of zero, leading to errors in polynomial division or finite difference calculations.

Explain: A polynomial must include all powers from the highest degree down to the constant term. If a term is missing, it means its coefficient is 0. For example, the polynomial x^3 - 2x + 5 is actually x^3 + 0x^2 - 2x + 5. This is important when writing polynomials in expanded form, performing polynomial division, or setting up finite difference tables.

Example: Consider the polynomial x^4 - 2x^3 + 5. The missing x^2 and x terms have coefficients 0. So the full expanded form is x^4 - 2x^3 + 0x^2 + 0x + 5.

err-piecewise-endpoint-circles

The student confuses the use of solid and open circles for piecewise function endpoints: solid circles are used for inclusive inequalities (≤, ≥) and open circles are used for strict inequalities (<, >).

Explain: When graphing piecewise functions, the endpoints of each piece must be marked with a circle to indicate whether the point is included or not. Use a solid (filled) circle if the inequality includes 'or equal to' (≤ or ≥). Use a hollow (open) circle if the inequality is strict (< or >).

Example: For the function f(x) = { x+1 for x < 2; x^2 for x ≥ 2 }, at x=2: the first piece (x < 2) has an open circle at (2,3); the second piece (x ≥ 2) has a solid circle at (2,4).

err-finite-difference-degree-determination

Student miscounts the number of differences needed to reach a constant, leading to wrong polynomial degree.

Explain: To determine the degree of a polynomial using finite differences, compute successive differences until you obtain a constant row. The number of times you compute differences (the order of the constant difference) equals the degree. For example, a cubic polynomial has constant third differences (e.g., 6), and a quartic polynomial has constant fourth differences (e.g., 24).

Example: Consider a cubic polynomial: first differences vary, second differences vary, third differences are constant (all 6). Thus degree = 3. For a quartic polynomial, fourth differences are constant (all 24), so degree = 4.
