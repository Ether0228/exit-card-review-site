补救模块

err-remainder-theorem-evaluate-at-wrong-value

Students misunderstand that the Remainder Theorem requires substituting the value that makes the divisor zero, not just the constant term with the opposite sign.

Explain: The Remainder Theorem states that when a polynomial p(x) is divided by x - b, the remainder is p(b). For a divisor like x + b, rewrite it as x - (-b), so substitute x = -b. For a divisor like ax - b, set ax - b = 0, solve for x = b/a, then evaluate p(b/a).

Example: For p(x)=x^3+7x^2+2x-5 divided by x+7, set x+7=0 => x=-7. Compute p(-7)=(-7)^3+7(-7)^2+2(-7)-5 = -343+343-14-5 = -19. So remainder is -19.

err-factor-theorem-multiple-factors

Students incorrectly think the Factor Theorem only applies to factors of the form x - b (i.e., divisor with leading coefficient 1). They do not realize that for a divisor ax - b, the corresponding root is b/a, and if p(b/a)=0, then ax - b is also a factor.

Explain: The Factor Theorem says: x - b is a factor of p(x) if and only if p(b)=0. More generally, for a linear divisor of the form ax - b (e.g., 2x+1, 3x-2), we set ax - b = 0 to get x = b/a. Then ax - b is a factor if and only if p(b/a)=0. This extends the theorem to any linear binomial.

Example: Check whether 2x+1 is a factor of p(x)=12x^4-56x^3+59x^2+9x-18. Set 2x+1=0 → x=-1/2. Evaluate p(-1/2)=12(1/16)-56(-1/8)+59(1/4)+9(-1/2)-18 = 0.75+7+14.75-4.5-18=0. Since p(-1/2)=0, 2x+1 is a factor. Synthetic division confirms remainder 0.

err-rational-root-theorem-signs

The student does not realize that the Rational Root Theorem requires considering both positive and negative signs, or that every factor of the constant term can be paired with every factor of the leading coefficient.

Explain: The Rational Root Theorem states that for a polynomial with integer coefficients, any rational root in lowest terms p/q has p as a factor of the constant term and q as a factor of the leading coefficient. To list all possible rational roots, list all factors of the constant term (including both positive and negative) and all factors of the leading coefficient. Then form all fractions ±p/q, where p is a factor of the constant and q is a factor of the leading coefficient, and simplify. Always include both positive and negative signs.

Example: For p(x)=2x^3+3x^2-8x+3, constant term=3, leading coefficient=2. Factors of constant: ±1, ±3. Factors of leading: ±1, ±2. Possible rational roots: ±1/1, ±3/1, ±1/2, ±3/2, i.e., ±1, ±3, ±1/2, ±3/2.
