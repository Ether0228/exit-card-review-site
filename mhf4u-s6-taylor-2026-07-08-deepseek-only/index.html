补救模块

err-piecewise-open-closed-hole

Confusing whether to use open or closed hole at interval endpoints

Explain: In piecewise functions, each sub-function applies to a specific interval. At the endpoints of these intervals, we use open circles (holes) to show the point is not included, and closed circles (filled dots) to show it is included. Use '<' or '>' for open, and '≤' or '≥' for closed.

Example: Let f(x) = { x+1, x < 2; -x+5, x ≥ 2 }. At x=2: first piece has x<2 so open circle at (2,3); second piece has x≥2 so closed circle at (2,3). They join, creating a continuous graph.

err-piecewise-domain-interval

The student may think that all intervals start at negative infinity and end at positive infinity, or they may confuse open and closed boundaries, leading to incorrect domain intervals.

Explain: A piecewise function is defined by multiple sub-functions, each applied to a specific interval on the x-axis. The interval is given by an inequality (e.g., x < 2, x ≥ 0). To correctly identify the domain interval for a piece, focus on the inequality: it tells you exactly which x-values are allowed. For example, if a piece is defined for x < 3, then the domain interval for that piece is (-∞, 3). If another piece is defined for x ≥ 3, its domain is [3, ∞). A common mistake is to include endpoints incorrectly, such as putting 3 in the first piece when it should be in the second. Always check the inequality symbol: < and > are strict (open circle), ≤ and ≥ are inclusive (closed circle).

Example: Consider the piecewise function: f(x) = { 2x + 1, x ≤ 2; -x + 5, x > 2 }. The first piece has domain interval (-∞, 2] because it includes x=2. The second piece has domain interval (2, ∞) because it starts just after 2. If you mistakenly thought the first piece was for x < 2, you would miss including x=2, or if you thought the second piece included 2, you'd have two pieces claiming x=2. Intervals must be disjoint and cover the whole domain.

err-polynomial-degree

Student may think degree is based on the number of terms or include coefficients instead of focusing on the highest exponent.

Explain: The degree of a polynomial is the highest exponent of the variable x in the expression. It determines the function's shape and end behavior.

Example: In P(x)=4x^3+2x-5, the exponents are 3,1,0. The highest is 3, so degree=3.

err-polynomial-end-behavior

Student confuses the rules for end behavior: they may not correctly apply the effect of degree parity (even/odd) and the sign of the leading coefficient.

Explain: End behavior describes how a polynomial function behaves as x approaches positive or negative infinity. It depends on two features: the degree (even or odd) and the sign of the leading coefficient (positive or negative). For an even-degree polynomial, both ends go in the same direction: up if leading coefficient is positive, down if negative. For an odd-degree polynomial, the ends go in opposite directions: if leading coefficient is positive, the right end goes up and the left end goes down; if negative, the right end goes down and the left end goes up.

Example: Consider f(x) = -2x^4 + 3x^2 - 5. The degree is 4 (even) and the leading coefficient is -2 (negative). Therefore, as x→+∞, f(x)→-∞, and as x→-∞, f(x)→-∞. So both ends go down.
