Q4. Which of the following is a correct statement of Pascal's Identity?

Learning Goal: lg-4

Misconception: Student confuses the indices, e.g., thinks C(n, r) + C(n, r+1) = C(n+1, r) or similar.

Remediation → err-pascals-identity-direction | Retest → err-pascals-identity-direction

  1. ✓ A. C(n, r) + C(n, r+1) = C(n+1, r+1)
  2. B. C(n, r) + C(n+1, r) = C(n+1, r+1)
    The left side indices are incorrect. Use the same n for the first two terms.
  3. C. C(n, r) + C(n, r) = C(n+1, r+1)
    Both terms are C(n,r); identity uses consecutive indices in the second term.
  4. D. C(n, r) + C(n, r+1) = C(n, r+1)
    This would imply C(n,r)=0, which is false. The right side should be C(n+1, r+1).

补救模块

err-term-number-off-by-one

The student uses the term number directly as r in the general term formula instead of r = term number - 1.

Explain: The general term of (a+b)^n is T_{r+1}=C(n,r)*a^(n-r)*b^r, where r starts at 0. So the k-th term uses r=k-1.

Example: Find the 5th term of (x^2+2)^6. Since k=5, r=4. T_5 = C(6,4)*(x^2)^(2)*2^4 = 15*x^4*16 = 240x^4.

err-grid-path-total-steps

Student incorrectly adds or multiplies the east and north steps instead of summing them to find the total number of steps for choosing east moves.

Explain: For grid paths moving only east (E) and north (N), the total number of steps is the sum of east steps and north steps. Then the number of different routes is C(total steps, east steps) or C(total steps, north steps).

Example: From (0,0) to (6E,5N): east steps = 6, north steps = 5, so total steps = 6 + 5 = 11. Number of routes = C(11, 6) = 462.

err-pascals-identity-direction

Student misapplies Pascal's Identity by using incorrect indices, often confusing the relationship between the terms.

Explain: Pascal's Identity states that C(n, r) + C(n, r+1) = C(n+1, r+1). This means the sum of two consecutive combinations with the same n equals a combination with n+1 and the larger index. It reflects how numbers in Pascal's Triangle are formed.

Example: C(6,4) + C(6,5) = 15 + 6 = 21, and C(7,5) = 21, so the identity holds.

err-constant-term-exponent-sum

The student does not understand that a constant term has no variable, so the exponent of the variable must be zero. They may forget to combine exponents from both terms or solve the equation incorrectly.

Explain: To find the constant term in (a+b)^n, where a and b have variable factors, use the general term C(n,r)*a^(n-r)*b^r. Write each factor's exponent on the variable, add them, set the sum equal to zero, solve for r, then compute the coefficient.

Example: Find the constant term of (x+1/x)^10. General term: C(10,r)*x^(10-r)*(1/x)^r = C(10,r)*x^(10-2r). Set exponent 10-2r=0 → r=5. Constant term = C(10,5)=252.
