    补救模块

    err-binomial-geometric-confusion

    Student thinks any scenario with success/failure is binomial, ignoring that geometric counts trials to first success.

    Explain: Binomial distribution counts the number of successes in a fixed number of trials (e.g., number of heads in 10 flips). Geometric distribution counts the number of trials needed to achieve the first success (e.g., number of rolls until a 6 appears). Key difference: binomial has a fixed number of trials; geometric continues until the first success.

    Example: Rolling a fair die: 'Number of heads in 10 flips' is binomial (fixed 10 trials, count successes). 'Number of rolls until rolling a 6' is geometric (trials stop at first success).

    err-cumulative-skip-misuse

    The student thinks the complement rule applies the same way for all cumulative expressions, not realizing that 'at least' requires subtracting from 1 while 'less than' uses the cumulative directly.

    Explain: When calculating cumulative probabilities in binomial distributions, you can use the complement rule to avoid summing many terms. For 'at least X successes', P(at least X) = 1 - P(≤ X-1). For 'less than X', you directly use P(≤ X-1) without complement. For 'more than X', use 1 - P(≤ X). A common mistake is using complement for less-than problems or forgetting to subtract from 1.

    Example: In the advertising flyer example (n=20, p=0.15), P(at least 3 responses) = 1 - P(≤2) = 0.595. In the baseball example (n=10, p=0.28), P(less than 6 hits) = P(≤5) = 0.98, and P(more than 4) = 1 - P(≤4) = 0.12.

    err-expected-value-calculation

    Student does not recognize or apply the formula E(X) = n × p, instead tries to compute expected value by summing all possible values times their probabilities, which is inefficient and error-prone.

    Explain: For a binomial distribution, the expected value (mean) is simply the number of trials multiplied by the probability of success: E(X) = n × p. You do not need to sum anything because the formula is derived from properties of independent trials.

    Example: In a car purchase study with n = 5 couples and p = 0.7 (husband influence), E(X) = 5 × 0.7 = 3.5. So on average, we expect 3.5 couples (out of 5) where the husband influences the purchase.

    err-at-least-vs-more-than

    The student thinks 'at least X' excludes X itself (like 'more than X') or thinks 'more than X' includes X (like 'at least X'). This changes the cumulative probability boundary.

    Explain: In binomial probability, 'at least X successes' means X or more (X, X+1, ..., n). 'More than X successes' means strictly greater than X (X+1, X+2, ..., n). The difference is whether X is included. For cumulative calculations, 'at least X' uses complement: P(at least X) = 1 - P(≤ X-1). 'More than X' uses complement: P(more than X) = 1 - P(≤ X).

    Example: In the advertising flyer problem (n=20, p=0.15), P(at least 3) = 0.595, which includes exactly 3. P(more than 3) would be 1 - P(≤3). Using P(exactly 3)=0.243, P(more than 3) = P(at least 3) - P(exactly 3) = 0.595 - 0.243 = 0.352.
