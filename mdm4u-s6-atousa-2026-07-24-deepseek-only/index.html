补救模块

err-hypergeometric-mean-formula

The student may have used the binomial expectation formula E = n * p instead of the hypergeometric formula E = n * K / N, or may have incorrectly applied the hypergeometric formula by using the wrong values for K, N, or n.

Explain: The hypergeometric distribution models draws without replacement. Its expected value (mean) is given by E = n * K / N, where n is the sample size, K is the number of successes in the population, and N is the population size. This is different from the binomial expectation E = n * p, which requires a constant success probability p. For hypergeometric, the probability of success changes with each draw, but the expectation formula still holds.

Example: In the jury example, we have N = 25 total people, K = 11 women (success), and we select n = 12 jurors. So E = 12 * 11 / 25 = 132 / 25 = 5.28. This means we expect about 5.28 women on the jury.

err-binomial-condition-outcomes

The student thinks that a binomial distribution can be used when a trial has more than two possible outcomes, as long as one outcome is designated as 'success'.

Explain: The binomial distribution requires exactly two mutually exclusive outcomes for each trial. This is often called a 'success' and 'failure'. If a trial has three or more possible outcomes (like choosing a color from red, blue, green, yellow), the binomial model does not apply, because the probability of 'not success' includes multiple distinct outcomes that may not have the same probability. The conditions for binomial are: (1) fixed number of independent trials, (2) each trial has exactly two outcomes, (3) the probability of success is constant for each trial.

Example: Rolling a die: there are 6 outcomes. Even if we only care about getting a six, each roll still has six possible results. So rolling a die is not binomial unless we collapse to 'six' vs 'not six', which is valid only if each roll is independent and probability remains 1/6. Actually, collapsing to two outcomes is fine because we are only modeling the count of sixes. But if we try to model 'getting a 1,2,3,4,5,6' separately, it's not binomial. For binomial, we must define success and failure such that each trial results in exactly one of those two categories.

err-binomial-condition-independence

Students may overlook independence assumption, e.g., applying binomial to draws without replacement.

Explain: The binomial distribution requires that each trial be independent of the others. Independence means the outcome of one trial does not affect the probability of success in subsequent trials. For example, rolling a die multiple times is independent because each roll is separate; drawing marbles without replacement is not independent because the composition changes.

Example: Roll a fair die 4 times and count the number of sixes: each roll is independent, so binomial applies. But drawing 3 marbles from a bag without replacement changes probabilities with each draw, so it's not binomial.

err-binomial-prob-combination

The student believes that the probability of exactly k successes is simply the product of the probabilities, overlooking the fact that there are multiple ways to arrange the successes among the trials.

Explain: The binomial formula includes the combination term C(n,k) because we must account for all possible sequences of k successes and n-k failures. For example, with 4 rolls, getting 2 sixes can happen in C(4,2)=6 different orders (e.g., SSFF, SFSF, SFFS, FSSF, FSFS, FFSS). Each order has the same probability p^2*(1-p)^2, so we multiply by 6.

Example: For rolling a fair die 4 times, P(exactly 2 sixes) = C(4,2)*(1/6)^2*(5/6)^2 = 6*(1/36)*(25/36) = 150/1296 = 25/216 ≈ 0.1157. If you forgot the combination term, you would get only (1/36)*(25/36)=25/1296≈0.0193, which is too small.

err-binomial-expected-value

Student confuses expected value with variance or uses incorrect formula such as np(1-p) or n*p*(1-p).

Explain: The expected value (mean) of a binomial distribution is simply the number of trials multiplied by the probability of success on each trial: E = n * p. Do not multiply by (1-p); that is the variance formula.

Example: A basketball player has a 60% free throw success rate. In 3 attempts, expected makes = 3 * 0.6 = 1.8.

err-complement-misapplication

Student assumes P(fewer than 2) = 1 - P(exactly 2), forgetting that the complement of 'fewer than 2' is 'at least 2', not 'exactly 2'.

Explain: In probability, phrases like 'fewer than k' mean all values 0 to k-1. The complement of 'fewer than k' is 'k or more'. So P(fewer than k) = 1 - P(k or more). Always identify the event clearly before using the complement formula.

Example: For the blood type problem (n=5, p=0.25), 'fewer than 2' means X=0 or X=1. P(fewer than 2) = P(X=0)+P(X=1) ≈ 0.2373 + 0.3955 = 0.6328 ≈ 0.63. The complement of 'fewer than 2' is 'at least 2' (X≥2), so P(fewer than 2) = 1 - P(at least 2).
